# OBS Spatial FX v3.6：组合预设与实时图形方案

状态：研究草案，等待用户确认后开发。日期：2026-11-13。当前已交付产品仍为 v3.5.0。本轮不修改插件、安装器、版本号、使用说明书或 GitHub Release。

## 1. 建议实现的产品

在“预设”页选择一张卡片，出现该模板需要的几个位置，例如“主体”“背景”“前景”。用户从当前舞台已导入的图层中指定对应素材，调整动感、颜色、速度与装饰位置，预览后应用。模板同时安排这些素材的运动，并按需创建实时绘制的装饰图形。

示例：“斜带交叉·波普”需要一个主体图层，可选背景和前景。绑定后，主体轻微推近并倾斜，背景反方向缓慢移动，两条紫蓝斜带在用户指定的空间位置交叉、收拢、退出；可循环、改色、改尺寸和改深度。图形由插件实时计算，不需要用户制作透明 WebM，也不需要播放 AI 生成视频。

一个模板包括：配色、构图、角色槽位、图层运动、镜头运动、装饰图形、遮罩关系与时间安排。用户可以只启用其中一部分。

## 3. 参考图的可实现拆解

以下是对用户提供的五张静帧的观察和设计推导，没有原视频时序测量。

| 静帧中的构成 | 原生实现建议 | 用户主要设置 |
|---|---|---|
| 紫色和蓝色大矩形滑入/露出主体区域 | 矩形平面；位置与宽度变化；需要时作为遮罩 | 两种颜色、方向、覆盖程度、周期 |
| 两条斜带形成 X | 两条长矩形或平行四边形；独立旋转、偏移、相位 | 夹角、宽度、交叉中心、深度 |
| 人物靠近画面一侧，背景占据另一侧 | 主体与背景的独立位置/缩放，必要时小幅镜头运动 | 主体槽位、背景槽位、运动幅度 |
| 人物倾斜、推近和偏移 | 现有 XYZ/旋转/缩放参数轨 | 强度、方向、持续时间 |
| 圆形或椭圆边框包围画面 | 圆环/椭圆程序图形；独立大小、偏移与开合 | 中心、半径、粗细、颜色、深度 |

截图中的人物如果已经和背景合成为一个不透明视频，本插件只能移动整体或按几何区域裁切；要把色带真正放到人物后面，应绑定带 Alpha 的人物素材和独立背景。本版不做自动抠人、语义识别或 AI 重建背景。用户可用已有抠像或透明角色来源。

## 4. 预设怎样“好看”

模板设计需要约束画面，而不是把所有已有 FX 打开。

- **主体清楚**：默认保留主体附近的安全区域，装饰主要经过边缘和背景；用户可手动指定主体中心与安全范围，不暗中做人脸识别。
- **配色统一**：建议每套 2～3 个主色，另有背景与文字色；色板引用让斜带、描边和圆环同步改色。
- **动作有主次**：每段安排一个明显动作，其余图层保持低幅度运动；镜头运动与主体运动避免同时大幅叠加。
- **节奏有停留**：入场后给主体稳定展示时间，再退场或转场；连续直播默认提供舒缓档，强冲击和闪烁由用户主动选择。
- **循环可闭合**：几何、位置和颜色在首尾衔接；连续运动需检查首尾速度，不能只看两张静帧相同。
- **图形反复使用**：一套模板围绕斜带、圆形或网格中的一种主语汇展开，少量变形、相位和深度变化即可形成统一系列。

首批模板按“几何波普、柔和展示、节奏切换”分组，卡片数量保持少量；卡片内提供变体，减少用户一次要筛选的项目数量。

## 5. 三种技术路线比较

| 路线 | 优点 | 与当前需求的取舍 |
|---|---|---|
| 原生参数关键帧预设 | 能沿用现有编辑、曲线、撤销与工程保存 | 适合有限动作；单独使用难以产生独立装饰和长时循环 |
| 浏览器/脚本效果作为 OBS 来源 | 能较快展示 Canvas/Pixi/Three 类案例 | 另有浏览器纹理和时钟；深度、实例关联、安装与资源成本需要额外桥接 |
| **原生混合方案：关键帧＋循环模板块＋实时图形节点** | 图层运动可编辑，循环内存受控，图形可参与空间排序 | 需要新增模板编译、图形绘制和对象管理；推荐作为正式方向 |

推荐保持 C++17、Qt6、libobs 和现有 GS 渲染框架。预设是受验证的数据，执行已内置的数学动作和图形种类；本版不加载远程脚本、任意 JS/Python、用户 DLL 或任意着色器文本。使用预设不需要 AI 账号、模型 API 或联网。

## 6. 用户操作流程

1. **选预设**：卡片展示简短名称、缩略动画与需要的素材数量。
2. **选素材**：主体可选一个，背景和前景可选多个；只列当前舞台已导入实例，同源多实例分别显示。缺少可选角色仍可应用，必需角色未选则明确提示。
3. **调少量选项**：默认展开“动感、速度/周期、配色、开始位置”；“图形与遮罩”“空间位置”“高级时间设置”按需折叠展开。位置类连续参数沿用 0.01 步长。
4. **实时预览**：使用临时文档快照预览；“取消预览”回到开始前状态，切场景或换舞台结束该临时预览。
5. **应用到时间轴**：形成一次完整、可撤销的事务。时间轴显示本次生成的运动与装饰；同一模板再次应用会生成另一实例，不重复绑定到名称相同的旧对象。

现有“保存/应用当前整套预设”保留在“我的整套预设”折叠区；新卡片区负责局部角色模板。界面说明继续使用一秒悬停气泡，错误、冲突和状态直接显示。

## 7. 图层角色与绑定规则

- **主体**：一个图层实例。默认不换源、不重新裁剪、不重置基础位置。
- **背景**：零个或多个实例，用于慢速漂移或反方向移动。
- **前景**：零个或多个实例，用于更明显的视差、遮挡或局部划过。
- **镜头**：可选开关。模板默认只动指定图层；勾选“同时移动镜头”后才写相机轨。
- **装饰位置参考**：可选一个图层实例作为空间锚点，也可放在固定世界位置。
- **被遮罩对象**：与空间锚点分别选择，允许只遮主体、多个指定图层或整幅舞台。

绑定存 `instanceId` 和所属舞台身份，不按名称或列表行号。重排和重命名保留关系；移除被绑定对象后停用该绑定并提示，不能自动换到同源的另一个实例。

多背景/前景可设依次错开时间，默认有固定次序；随机变化使用保存的 seed，每次定位同一时间得到同一结果。锁定对象和锁定参数轨不能被模板静默改写。

模板布局用归一化画布位置与槽位内容框表达，再由当前舞台尺寸、源裁剪及导入补偿换成项目既定坐标。角色提供“保持原构图”“适应内容框”“填满并裁切”的明确选择，默认保持原构图；横竖画幅和来源尺寸变化须重算，不把作者在 1920×1080 的像素坐标硬套给所有素材。

## 8. 装饰、遮罩、转场的用户含义

同一个图形可提供三种明确模式：

| 模式 | 用户看到的结果 | 实现关系 |
|---|---|---|
| 彩色装饰 | 看得见的斜带、块、圆环，可遮住后方内容 | RGBA 图形参与空间合成 |
| 裁切遮罩 | 图形不直接着色，只决定指定素材哪些地方露出 | 生成覆盖率，乘到接收图层的预乘颜色和 Alpha |
| 装饰＋裁切 | 露出素材时同时出现有颜色的边/带 | 同一几何产生可见图形与独立接收遮罩 |

首批“转场”定义为舞台内指定图层的入场、退场、开合或 A/B 图层替换。A/B 需要两个可用实例；单个直播捕捉源不能凭空提供切换前后的两个画面。这一版不接管 OBS 的全局场景转场。

空间 Z 表示平面放置位置；遮罩目标决定谁被裁切。不会因为一张装饰卡位置靠近某层，就自动修改那层 Alpha。

## 9. 深度放置与运动

界面先提供容易理解的选择：“最前方”“在 A 与 B 之间”“跟随某层”；高级设置继续显示实际 XYZ、旋转、缩放和同深度顺序。

“在 A 与 B 之间”在应用时按当前相机与图层位置建议初始位置，保存为世界位姿，不在用户运镜时暗中把对象改成屏幕贴片。若用户选择持续跟随某层，明确保存局部偏移并使用该层求值后的变换。

世界图形与导入图层使用同一个 `evaluateSceneAt()`、`effectivePlane`、相机投影及深度排序。“固定屏幕位置”是可选的界面贴片模式，默认关闭；它不宣称具有空间遮挡。

目前渲染以平面中心深度排序。首批以平行或近似平行的 2.5D 图层为验收范围；相互穿插的倾斜平面不能保证像真实三维网格一样逐像素遮挡。空间参考图仍是结构示意，实际 OBS 输出才是验收画面。

## 10. 时间轴与循环规则

### 有限运动

入场、退场、短推近等动作优先写为现有参数轨关键帧，可继续用现有曲线编辑。应用位置默认取播放头；动作值按当时求值位置生成相对变化，不能把用户初始布局拉回模板作者的坐标。

若模板所用参数和已有关键帧发生冲突，预览列出具体对象、参数与区间。默认保留原轨并停止提交；用户选择“替换此区间”后才覆盖，其他参数和区间保留。边界使用现有精确曲线拆分能力，并验证区间外曲线不变。不能只追加几个点，任由插值改变区间外画面。

### 循环模板块

周期动作和装饰以一个模板块保存起点、周期、相位、次数/终点和强度；播放时根据绝对时间求值，不为每一轮追加关键帧。可在有限区间循环，也可让整个舞台按现有循环播放功能重复。

时间轴显示循环块的实际跨度和周期刻度。创建块时生成其显式边界时间标记/关键帧；扩展 `contentEnd()` 读取新增对象与模板轨中最晚保留的关键帧，继续以内容决定终点。不会恢复旧的独立工程播放范围。持续时间不设人为的短时上限，底层继续使用 int64 微秒，所有换算检查溢出。

内部相位为 `fract((t - start) / period + phase)`，负时间、零周期、NaN 和超界值在加载/提交前校验。匀速滚动用平铺闭合；来回运动用往返曲线；入场/停留/退场各有时间段；周期闭合需要颜色、透明度和速度的一致性。

暂停时模板停在当前状态，拖到任意时间直接求对应画面。预设不能另开一个随系统时间不停走的时钟。现有 FX 的历史缓冲行为单独回归，不在这次研究中承诺所有旧残影效果可无历史随机定位。

### 可编辑性与叠加

循环运动作为单独模板轨，手动轨保留。参数编辑器标出被模板控制的通道；有限动作已经是普通关键帧，可直接编辑。循环运动如需逐点编辑，提供“转换选定区间为关键帧”，预览采样数量并确认后转换；不无限展开。

位置偏移默认使用世界轴加法，旋转偏移沿现有度数和 `Rz * Ry * Rx` 规则，缩放和透明度使用乘法；相机环绕模式只驱动对应环绕参数，不能让 XYZ 与环绕约束同时争夺位置。求值顺序统一为：手动参数轨 → 模板参数变化 → 环绕/朝向约束 → 导入补偿/effectivePlane → 灯光绑定 → 投影/合成。详细公式在实现前补入统一坐标约定并单测，不让预设模块另写一套投影。

v3.6 首批默认每个对象同一通道只允许一个循环模板块在同一时间生效；相互重叠时提示，暂不引入复杂多轨混合权重。使用模板轨的对象仍可在未受控通道打普通关键帧。

## 11. 原生图形如何生成

- 矩形、平行四边形、斜带：缓存单位几何，变化通过参数和变换传入。
- 圆、椭圆、圆环、软边：小型解析覆盖率/SDF shader，在图形边界计算抗锯齿，不默认增加全画面 SMAA 或 FXAA。
- 网格、条纹、棋盘：有限公式平铺，用画布/图层尺寸归一化，避免每格建立一个独立来源。
- 星形、多边形：固定顶点图元或有界解析函数，限制边数和重复数量。
- 擦除/快门/虹膜：同样几何输出单通道覆盖率，按目标生成/复用遮罩纹理。
- 首批无需真实粒子物理、实时文字逐字排版、3D 模型或视频解码。粒子若以后加入，用固定 seed 与解析轨迹，避免依赖上一帧模拟状态。

可见装饰和遮罩共享几何定义，按需分别渲染。图形边界使用覆盖率处理预乘 Alpha，避免黑边、白边和叠色错误。世界遮罩按同一相机投影；贴到单个图层的局部遮罩使用该图层的局部 UV。两种空间明确区分。

## 12. 与现有工程的接入点

本节依据本地 v3.5.0 源码读取，属于改动建议。

| 接入处 | 现有情况 | 建议改动 |
|---|---|---|
| `src/dock.cpp`、新预设面板 | 当前是整套预设下拉与保存按钮 | 新增模板卡片、角色绑定与临时预览；旧整套预设折叠保留 |
| `src/model.hpp/.cpp` | StageModel 有图层、相机、灯光、参数轨 | 保存模板实例、图形对象、角色关联、seed、参数与版本 |
| `src/scene_evaluator.*` | 统一位置、旋转、缩放、灯光和投影前位姿 | 加入模板参数求值与虚拟图形的纯数学输出 |
| `src/animation.hpp`、`editor*` | 参数曲线、微秒时间、精确拆分、撤销 | 保留普通轨格式，增加模板块显示、冲突处理与有限烘焙 |
| `src/stage.cpp` | 32 个导入图层的固定缓存与绘制数组 | 图形另设有界缓存和绘制项，与原图层统一排序；不能直接突破数组边界 |
| 新 `src/presets/` | 无角色模板编译器 | 受验证的数据目录、编译/绑定、预览事务及模板版本快照 |
| 新程序图形渲染模块 | 无独立程序图形对象 | 图形与覆盖率生成、缓存、图形上下文生命周期 |
| `src/project/` | v3.5 保存来源设置并重写 UUID/instance_id | 新图形和模板身份需纳入映射，测试同源多实例、跨工程导入及独立移除 |

初步数据职责：模板目录保存“需要哪些角色、有哪些动作、创建哪些图形”；模板实例保存“用户绑了谁、用了什么值、放在哪段时间”；编译结果保存给求值/渲染的不可变数据。当前预设版本内容应随工程保存，避免插件更新后旧直播场景视觉悄悄改变。

图形在舞台内作为虚拟对象出现，可在时间轴选中、隐藏、改深度、移除；默认不创建大量 OBS 独立来源，也不占用现有 32 个素材导入槽。32 层现有限制保持，图形上限和总绘制预算在性能样机验证后固定。不能把图形对象简单伪装成没有 sourceUuid 的普通素材，绕过资源与依赖处理。

## 14. 节拍接入

默认用秒，完全没有音频也能工作。用户选择已有音频分析后，可把周期设置为 1/4、1/2、1、2、4、8 拍，并沿用已有 BPM、拍点偏移与最小间距规则。

v3.6 首批使用现有分析结果/手动 BPM 驱动预设相位和关键帧时间，不新增直播音频实时识别。非等速音乐若只有单个 BPM，会漂移；可采用已分析拍点列表映射时间，仍应允许手工调整。本轮未实测此接入。

## 15. 性能与稳定性验收计划

以下均为 **NOT RUN**，只规定将来开发时必须记录的内容。

- 关闭预设后不执行新增图形和遮罩 pass；初始化后不每帧创建纹理/着色器/OBS 来源。
- 不带遮罩的简单几何尽量直接绘制；同一素材捕获结果复用；遮罩按接收目标和尺寸缓存，不盲目为每个小图形创建全画布纹理。
- 简单图形默认不启用舞台灯光、阴影、全画面模糊或光晕；需要时由模板选项单独开启，评估额外成本。
- 所有 `gs_*` 在合法图形上下文；UI 发布快照，渲染线程不等 UI、不读文件；删除预设/关闭舞台正确退役资源。
- 对比同一场景的关闭、有限运动、纯装饰、单目标遮罩、多图层组合；分别记录 CPU、内存、GPU 帧耗时、纹理数量、渲染/编码跳帧和运行时长。
- 验证分辨率、FPS、源尺寸变化、32 层边界、图形上限、暂停/拖动/循环接缝、多次应用/撤销、切场景、来源移除、OBS 退出。
- 使用用户序列相近的主体/背景结构，验证装饰在人物前、中、后三种深度的实际输出。测试素材自行绘制或使用明确可用的素材，不把仓库演示中的角色/品牌素材打包。
- 真实 OBS 33.0.1 上执行最终安装载荷测试；开发机通过后记录实测范围。核显机器验证仍需真实机器，不能用 RX 6900 XT 数据代替。

## 16. 研发顺序与交付边界

1. **时间与数据样机**：验证模板角色、ID、相对运动、曲线冲突、确定性循环和 v3.5 工程保存。先使用极简图形，记录功能/性能。
2. **三个核心模板**：矩形、斜带、圆/椭圆；实现可见装饰与指定目标遮罩；真实 OBS 检查空间位置与循环接缝。
3. **预设页**：卡片、绑定、少量主要选项、临时预览、应用/撤销/移除；时间轴出现新生成对象和模板块。
4. **扩展与节拍**：按用户选定目录增加模板变体，并接现有 BPM/拍点功能。
5. **兼容与交付**：v3.5 存档迁移、新工程导出/导入、回归、安装升级、证据与源码打包。发布需用户指示，说明书仅按明确要求更新。

建议用户先确认：原生混合路线、前三张核心卡片、装饰/遮罩三种模式、默认只移动指定图层且相机需手动启用。确认后再制定逐文件实施计划并开始编码。
