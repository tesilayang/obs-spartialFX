# v3.6.2 灯光修复记录

范围：新增灯光初始位置、软阴影可见性、灯光页紧凑布局。说明书不更新。

## 已复现

- v3.6.1 新灯光固定为 (-500,-300,-700)，不跟随导入构图。
- 实际 GPU Alpha 投影与软硬半径已生效；高环境补光 0.83、弱直射 0.12 的复现中，阴影 ROI RGB 差值仅 12.23，低于本次可见性门槛 20。
- 真实用户场景只读诊断：环境补光合计 0.83；部分人物位于桌面后方，不满足向前方桌面投影的几何条件。
- 原始失败证据保留于 work/v3.6.2/red-repro。

## 实现规则

1. 新灯光从 evaluateSceneAt 的当前求值结果计算：可见且启用、非零透明度的导入层，取裁剪后的四角及当前相机坐标；在最近四角之前留出安全间隔，位置对齐构图投影包围盒中心。中心限制在画面内侧 80%，无有效素材时置于镜头前 500 世界单位。已有灯光位置不迁移。
2. 每盏舞台灯的补光、直射与轮廓光使用该灯自己的遮挡可见度；其他灯的补光独立。补光总上限仍为 2，原有空间前后判定、Alpha 遮罩及九样本软阴影保留。
3. 灯光页数值行高度与间距单独压缩，目标行距约减少 30%，其他页不变。
