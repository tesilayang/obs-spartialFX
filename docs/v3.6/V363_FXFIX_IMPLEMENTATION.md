# v3.6.3 FX 光影修复开发记录

日期：2026-11-14。版本保持 3.6.3，交付目录为 `dist/v3.6.3-fxfix`。历史 v3.6.3 交付物保留。

## 根因与修复

1. `FX05.5` 通过固定局部灯架计算方向，界面没有独立角度；九点 Alpha 取样也会产生重复轮廓。改为图层局部二维角度、距离、遮罩扩张和连续可分离高斯卷积。模式仍为外投影／内阴影；增加角度、扩散、辅助强度，保留阴影强度、混合强度、距离、模糊。阴影颜色与辅助颜色分开。辅助强度控制相反侧内边缘的辅助色。
2. `FX04.0` 向 RGB 加光时保留原 Alpha，透明轮廓外的光被预乘时清除；渲染四边形也只有原素材尺寸。现在发光同时产生覆盖率，并按最大扩散距离预留透明边界、扩大绘制四边形。两种模式共用连续高斯光场，分别执行光量相加和柔光屏幕混合，增加独立颜色。
3. `FX04.1` 原先只有 24 个稀疏远距离取样，容易漏掉细小高光。现在先按目标色和亮度阈值提取种子，连续预滤波，再沿每条射线积分 32 次。积分光场最长边限制为 512；最后合成回原处理分辨率。射线为均匀分布的 2、4、5、6 条；五射线实际是五个方向。效果颜色和目标颜色分开，颜色容差按 RGB 最大通道差计算。

## 渲染与坐标约定

- 共享场景坐标仍由 `evaluateSceneAt()` 求值。新增边界只改变图层的绘制范围，不修改图层位置、旋转、缩放、关键帧或基础布局。
- 原处理纹理大小为 W×H，边界为 P。扩展纹理为 `(W+2P)×(H+2P)`；逻辑 UV 映射为 `(P+UV×(W,H))/(W+2P,H+2P)`。
- P 按启用光效的最远贡献距离求和后按 32 像素量化，降低拖动微小参数时的重分配。全部关闭后无光效边界或对应处理。
- 扩展像素换算回原素材尺寸后再交给现有平面投影，处理裁切、旋转、负缩放和动态尺寸。遮罩同时使用相应的纹理坐标映射。
- 局部光效在表面处理之后合成。全局投影读取局部光效之前的表面及其几何遮罩；局部阴影和光晕不成为第二个全局遮挡物。接收层的全局阴影遮罩继续在原平面范围取样。
- 新旧纹理使用分离的缓存目标，避免同纹理读写及普通尺寸／扩展尺寸每帧切换；预乘 RGB 和 Alpha 一起插值。渲染线程不新增锁、UI 等待或逐帧纹理／着色器创建。
- 所有颜色沿用整行预览、色值和选择按钮；实时修改、确认与取消恢复沿用统一颜色对话框。

## 数据迁移

- 新光效序列化写入 `optics_revision: 1`。
- 原辉光／星芒保存的颜色之前未参与渲染，迁移时初始化为白色，避免旧无效默认颜色突然染色。
- 原星芒四射线保留四条，六射线保留六条，移除的八射线映射到六条。旧工程缺少 `tolerance` 时初始化为 1，保留原先所有高光参与的范围；新建效果默认匹配白色、容差 0.15。
- 删除阴影的 `scale` 受光表面参数；旧 `scale` 不会解释为新角度。旧工程角度初始化为 135°，扩散和辅助强度初始化为 0。保留模式、距离、模糊、浓度、混合、阴影颜色。
- 新参数通过原有具名参数存档；单位测试验证精确往返，真实 OBS 验证退出重启恢复。
