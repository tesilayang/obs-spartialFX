# v3.6.2 软阴影连续性修复记录

日期：2026-11-14。版本号保持 3.6.2；原交付保留于 dist/v3.6.2，新修复包另存 dist/v3.6.2-shadowfix。

## 复现与根因

实际 OBS 33.0.1：半径 80、160、300 的阴影边缘最大相邻像素跳变均为 16；半径 300 出现三个分离轮廓，渐变区仅 20 像素。旧算法采样九个偏移光源的硬投影并平均；加大偏移只拉开轮廓，不会形成连续半影。失败证据保留 work/v3.6.2-shadowfix/red。

## 实现

- 每个投影物先按原空间求交算法生成硬 Alpha 阴影。
- 根据接收平面方向、素材与接收面距离、光源与素材距离，换算接收面局部 XY 模糊半径；接触面保持清晰。
- 复用降采样与相邻像素双向高斯卷积，支持两个轴各自半径。旧 FX 默认使用相同 XY 半径，卷积公式保持不变。
- 横纵方向分别扩展捕获边界、分别决定降采样，保留细长接收层的窄轴细节。
- 按 X/Y 降采样级数组合缓存目标；不同深度投影物共享卷积器时不反复调整同一缓存尺寸。
- 在接收平面外预留模糊边界，连续模糊各个投影，再按 Alpha 合成；保留孔洞、裁剪、透明度、独立灯光和接收层判定。
- 纹理、卷积着色器、降采样链缓存复用；分配、绘制及失败计数进入现有指标。
- 着色器文本在来源创建时读取；渲染回调只编译缓存文本并复用资源。

## 计算范围与数据兼容

硬投影继续使用原有射线与接收平面求交。半影宽度使用投影物中心深度近似，XY 世界半径 = 光源半径 × 投影物到接收面的垂直距离 ÷ 光源到投影物的垂直距离，再除以接收面对应轴的物理尺寸并乘 512。高斯 sigma 为该轴采样半径的 1/3，接触面距离为零时保留硬阴影。阴影图仍为 512×512。

模型字段、滑条范围、世界坐标、旋转和动画求值规则均未改变，无需迁移存档。已有大半径参数会得到连续柔化后的新效果。算法为本项目实现，未新增第三方代码与依赖。
