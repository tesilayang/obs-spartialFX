# OBS Spatial FX v3.6.6-b 预设重构计划

方案已确认。装饰与风格的实际成片效果为本版首要验收项。评审对象是一次随机预览从选对象到写入时间轴的完整体验。

## 1. 用户怎样操作

选一张风格卡 → 勾选对象 → 点「随机预览」。对象列表每行对应一个已导入实例，旁边设「参与运动」「接收转场」两列，可分别勾选。装饰用单独的「画面装饰」控制。预览区显示本次运动对象数、蒙版接收对象数和装饰组数。预览满意可应用或补充至时间轴，也可单独换运动、换装饰、换蒙版。

建议首次打开时，仅当前选中的素材勾选运动，没选素材时提示点选。转场列默认全空，装饰默认关闭。用户可以只做转场、只加装饰，也可以同时使用三项。详细控制沿用手动选模板、颜色及放置深度的入口。

示例：让角色轻轻向镜头靠近，只让标题擦入，同时在背景与角色之间划过一条彩带。用户在角色行勾运动、标题行勾转场，打开少量装饰并指定两层之间。换一次彩带后，角色的动作和标题的擦入时间保持一致。

## 2. 三项改动

| 模块 | 拟实现的画面 | 实现与限制 |
|---|---|---|
| 随机运动 | 斜推靠近、横移拉远、前后错层漂移。一个镜头有一个清楚的运动方向，前中后景按距离形成视差 | 读取当前镜头和对象深度，用统一场景求值估算屏幕位移与投影尺寸。普通位置轨写入 X/Y/Z，环绕对象使用对应的角度与半径。提供「平面／空间」选择，默认空间。空间模板至少有一段有效纵深变化。生成前检查近裁剪、意外穿层及主体出框。位置受限时减幅或换模板。全局镜头运动由用户显式选择，其作用范围标为整幅画面。 |
| 随机装饰实体 | 纸片风在画角放一组错落的纸签，节奏风在主体后方让一束彩带掠过，柔和风在边缘浮出低对比色面 | 每个风格先设计用途、配色、轮廓、入退场与可放置区域，再在这些范围内随机。建议「少量」最多一组主要图形和一组呼应图形。保留实心和半透明填充。默认优先边角或指定主体后方；用投影边界估算遮挡，空间不足时减少或跳过图形。透明窗口可能占满画布，详细控制允许手选保护区域，不要求逐帧识别人脸。 |
| 随机转场蒙版 | 同一镜头中只给标题擦入，也可给两个指定实例同步揭示，背景和角色继续原样显示 | 当前 `composer.cpp` 按运动的 `selectedIds` 为每个实例创建蒙版。新增独立的接收实例列表，空列表生成零个蒙版。提供「复制运动选择」作为一次性快捷操作，复制后两列仍可分别修改。默认同一次转场共用方向、节奏和随机细节，详细控制可选择素材局部坐标或舞台坐标。 |

## 3. 时间轴与兼容

运动、装饰、蒙版分别保存选项、随机种子和解析结果。只换一项时，另外两项的对象、关键帧和时序保持一致。同源多实例按实例 ID 区分，删除对象后清除失效选择。已锁定轨道跳过并提示。有限运动生成普通可编辑关键帧。补充预设沿用现有时间轴末端逻辑，新增片段首帧对齐追加点的姿态。取消预览和撤销应用须恢复原状态。

新配方显式保存两组对象。旧工程优先恢复已保存的关键帧、装饰与蒙版实体。只有重放旧版配方时，才按旧规则解释缺少的蒙版列表；新版明确保存的空列表始终表示无人接收。导入深度、投影和灯光仍复用现有坐标约定。

## 4. 实施顺序与验收

1. **先建立对照场景。** 在 OBS 33.0.1 准备背景、透明角色、桌面前景、标题四层，并增加一个同源角色副本。记录固定种子的现版画面、轨道和蒙版接收者，作为改动前基线。
2. **先拆对象选择，再重做运动。** 验证「只运动」「只转场」「一层同时参与两项」「同源副本只选一个」「两列全空仅加装饰」。用前、中、后三个时刻的 OBS 输出测可见主体的中心和宽度。建议以标准档推近镜头主体投影宽度变化 5%～12% 作为首轮调校目标，同时检查真实深度轨、前后景相对位移及循环接缝。
3. **再做装饰与蒙版的画面评审。** 每种风格至少抽三组固定种子，出无装饰／少量装饰同帧对照，以及入场、中段、退场三帧。检查主体与标题是否清楚、图形是否承接动作、密集构图能否主动减量。蒙版专项关闭运动和装饰，用差分图确认未选对象在独立测试区域内像素保持一致，所选对象有可见揭示过程。
4. **最后验证写入和交付。** 各实现阶段真实编译，专项检查单项重抽、取消、应用、补充、撤销、重开工程和旧配方回放。用相同 1080p60 场景分别测关闭预设、仅运动、三项全开时的渲染耗时和丢帧，记录硬件、采样时长和实体数。通过后打包 v3.6.6-b，在隔离 OBS 33.0.1 验证安装载荷，交付源码、安装器、效果对照和测试报告。

实施结果见同目录的开发与测试记录。
