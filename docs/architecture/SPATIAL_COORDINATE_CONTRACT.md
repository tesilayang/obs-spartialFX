# Spatial FX 统一坐标与动画求值约定

状态：v3.2 实现约定，2026-10-31。代码入口 src/scene_evaluator.hpp/.cpp；操作和真实验收见 docs/v3.2。

适用模块：空间图层、摄像机与时间轴、结构预览、灯光绑定、FX 空间效果、预设与配置迁移。后续模块不得另写一份世界坐标换算。

## 1. 必须保留的 v3.1 基准

| 概念 | 统一约定 |
|---|---|
| 世界原点 | OBS 画布中心所对应的世界参考点，不是左上角 |
| 轴向 | X 向右、Y 向下；默认相机沿 +Z 观察，Z 增大代表默认镜头下更远 |
| 世界距离 | 使用现有世界单位；不宣称任意相机下 1 单位都等于 1 屏幕像素 |
| 默认相机 | position=(0,0,−1500)，rotation=(0,0,0)，垂直 FOV=40° |
| 图层旋转 | 角度单位为度；使用现有 `Rz * Ry * Rx` 欧拉顺序，不能在不同页交换顺序 |
| 图层中心 | 旋转、缩放的默认中心为图层几何中心；保留原始裁剪及 OBS 导入布局补偿 |
| 缩放 | 内部使用倍率；v3.2两页明确显示倍率：1.0=原大小；未来改百分比须两页同时转换 |
| 透明度 | 内部 0～1；v3.2面板同为0～1。最终预乘 Alpha 的 RGB 和 Alpha 必须同时缩放 |
| XYZ 滑条 | 固定 −2000～2000，步长 0.01；数值框保留 −100000～100000，超范围只钉住滑块 |
| 数值与动画 | 数值是绝对值，不是相对于初始滑块的增量 |
| 对象身份 | source UUID + scene UUID + sceneitem ID；重命名及排序不能换绑到同源的另一实例 |

若后续需要扩大数值框范围，必须统一修改参数元数据、序列化、求值和测试，不能只改一个页面。

## 2. 一个基础状态、一条求值链

每个对象都有基础状态 BaseState、导入默认状态 ImportDefaults 和按参数存储的 AnimationTracks。基础状态不随播放头移动而被覆盖。导入默认状态用于用户确认后的复位。

一次统一求值按以下顺序执行：

1. 从同一不可变文档快照读取基础状态、参数轨道及播放头时间。
2. 求值每个启用动画的参数。没有动画或动画停用的参数取基础值。
3. 解析自由位置或环绕约束，产生 AuthoringPose；它是两个属性页面显示的“当前时间值”。
4. 应用已有跟随源尺寸、裁剪、边界框及导入布局补偿。
5. 应用兼容现有视差倍率的 effectivePlane 变换，得到 RenderWorldPose。
6. 绑定灯光依 RenderWorldPose 解析局部坐标，产生世界位置。
7. 解析相机模式及看向目标约束，生成 CameraPose；根据它进行透视投影、深度排序和景深距离计算。
8. 渲染光影和 FX；最后执行单独标明的全画面合成缩放/透明度。

统一入口为 `evaluateSceneAt(document, timeUs, sourceLayouts)`，返回 `EvaluatedScene`。它属于纯数学求值层，不调用 Qt、obs_source_update 或 gs_*。源尺寸以输入数据传入；读取 OBS 资源的职责在桥接层。

UI、结构预览、灯光和渲染都使用这个入口，不各自重新插值。完整求值可以分别在 UI 和 render 对同一输入执行；UI 不等待 render，render 也不等待 UI。播放时 UI 只跟随已发布的实际播放时间。

## 3. 两个属性页面如何联动

- 空间图层页与新属性编辑器使用同一个 ParameterRegistry 和 EditorController。
- 两页显示“基础布局”或“动画预览 @ 2.000 秒”状态，不能把两个不同时间的值放在同一标签下。
- 用户从时间轴选中图层后，空间图层列表和结构图联动选中同一身份；只切换对象不自动改变播放头。
- 在相同编辑状态、相同时间下，两页 XYZ/旋转/缩放/透明度相同。
- 时间轴预览时，已启用动画的参数修改当前关键帧；未启用动画的参数修改基础值。界面用动画开关、菱形和状态文字显示区别。
- 明确的“编辑基础布局”命令暂停预览并切换到 BaseState，不通过关闭窗口或切标签隐式改变编辑状态。
- 刷新、选择、播放、暂停、拖播放头、关闭 Dock 都不能写回插值值作为基础状态。
- 需要基础布局的整体挪动时，使用单独的偏移命令；本次不把它混进 XYZ 原有输入语义。

## 4. 保留视差补偿的数学含义

现有 `effectivePlane` 以参考距离 1500 做补偿。原位置 `(x,y,z)`、缩放 `(sx,sy)`、倍率 p：

    factor = (1500 + z*p) / (1500 + z)
    RenderWorldPosition = (x*factor, y*factor, z*p)
    RenderWorldScale = (sx*factor, sy*factor)

当前在 `abs(1500+z)<=20` 时跳过补偿。该行为及近裁剪深度 10 先作为兼容约束保留；若改算法，必须有独立变更记录和 GPU 前后对照。

AuthoringPose 和 RenderWorldPose 不是同一个坐标。输入框编辑前者；灯光绑定和最终几何使用后者。不能把已补偿的坐标再保存到基础位置，造成二次补偿。

现有结构图使用的几何与实际合成有差别，重制时应改为读取统一 RenderWorldPose，保留“示意比例”的说明，避免把斜二测投影误认作相机视频预览。

## 5. 环绕和朝向

“自转”改变自身旋转，“环绕”让中心围绕目标移动，必须分别命名。

环绕参数包括目标点 P、半径 r、水平角 yaw、俯仰角 pitch、滚转 roll（相机）。基础几何定义为：

    orbitPosition = P + rotate((0,0,−r), (pitch,yaw,0))

角度正方向沿用 rotate 的既有轴约定。首帧切换到环绕模式时，从当前位置反解参数，维持当前画面；半径为零时禁用角度调整并提示，不能产生除零/NaN。

自由位置模式和环绕模式互斥地决定位置。不能同时让 XYZ 轨道和环绕角度争夺同一最终位置。切换时先暂停；如果旧模式已有动画，默认保留旧轨并停用，提供明确的采样烘焙转换，不能静默丢帧。层的朝向默认保持自身旋转；相机可选始终看向目标。看向目标开启时，其驱动的俯仰/偏航显示为派生值，滚转单独生效，不提供可编辑却被立即覆盖的字段。

旋转有“最短路径”和“保留圈数”两种策略。旧动画默认最短路径；环绕角度允许连续 0→360→720，不能统一套用 remainder 而消除整圈运动。

## 6. 灯光与 FX 后续必须复用的接口

局部灯光位置 offset 绑定到图层时，保持 v3.1 原则：

    worldLight = RenderWorldPosition
               + rotate((offset.x*RenderWorldScaleX,
                         offset.y*RenderWorldScaleY,
                         offset.z), RenderWorldRotation)

XY 偏移跟随图层缩放，Z 是世界单位的局部深度；若之后需要 Z 缩放，必须升级约定版本并迁移，不能某个页面先行改变。

- 动画后的图层位姿、环绕和缩放均先求值，然后解析灯光绑定。
- 原项被重命名或列表拖动不改变身份；删除目标后明确标记绑定失效，禁止按名称或第一个同 UUID 图层自动重绑。
- FX 的景深、空间遮罩、距离衰减使用同一个 CameraPose/RenderWorldPose。
- 全画面合成缩放只改变最终输出，不回写世界坐标；全画面透明度也不叫“相机透明度”。它们不改变世界距离、灯光锚点或景深焦平面。
- 关闭 FX 不关闭几何动画、合成缩放和透明度；继续保留 v3 的默认不参与光影行为。

## 7. 时间和曲线约定

- 文档时间以有符号 64 位微秒 TimeUs 表示，非负；OBS/Qt 时间单位在边界处显式转换。
- 存储长整型时保留 JSON 数值精度；跨 QJson/脚本桥接采用十进制整数字符串，不隐式经过 double。
- UI显示秒；帧吸附按 OBS 实际有理数帧率换算，不假定永远 60fps。
- 同一参数同一规范化时间最多一个关键帧；编辑同点是更新，不依据“相差 0.005 秒”合并。
- 每段出点/入点的时域插值规则明确；时间贝塞尔的横轴必须单调，采用求根后再计算数值的方式，不能直接把时间比例当曲线参数。
- 基础状态、自由运动/环绕轨道、求值结果和后置输出变换分层保存；UI 刷新不造成序列化副作用。

## 9. 最低一致性测试

1. 默认相机、已导入窗口捕捉、裁剪、负缩放、不同源尺寸，导入前后与 v3.1 相同。
2. 0/2 秒两关键帧，1 秒两页面字段、结构图和 GPU 使用同一插值位姿；BaseState 不变。
3. 拖图层排序、重命名、同源重复引用，当前对象和灯光绑定身份不变。
4. 图层运动、旋转、缩放、环绕后，绑定灯位置等于上述解析公式。
5. 移动播放头 10000 次，无持久化基础值漂移。
6. 所有编辑输入拒绝 NaN/Inf；退化半径、近裁剪、视差补偿奇点、相机与目标重合不崩溃。
7. 全画面 50% 透明度同步缩放预乘 RGB/Alpha；不会改变灯光空间位置或开启 FX。

## v3.4.2 背后柔光的素材局部坐标

- FX05.1 的背光 XYZ 是图层材质内的局部参数，原点为裁剪后素材中心，X 向右、Y 向下、Z 正值在素材背面；单位为原素材像素。图层最终位姿继续由 `evaluateSceneAt()` 求值，整个材质结果随后跟随图层变换。
- 受光表面比例乘在局部表面坐标上；不修改图层基础坐标，不写入世界灯光位置，不替代灯光页的绑定公式。
- `sourceWidth/sourceHeight` 保留原素材尺寸，`width/height` 表示捕获纹理尺寸。表面位置为 `(uv - layer_uv_center) * source_size * scale`；高斯半径在提交捕获管线前乘 `captureWidth/sourceWidth`。最长边 2048 的捕获上限不能改变参数的像素单位。
- FX05.0 的“参考模糊”延续捕获采样画面的像素单位；其提示必须写明“参考采样画面像素”，不能与背光原素材像素混用。
