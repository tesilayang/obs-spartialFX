# v3.6.5 开发记录

日期：2026-11-16。范围：FX 页滚动及插件悬停提示；使用说明书不更新。

## 修改

- `src/fx_panel.cpp/.hpp`：提取布局签名。子功能开关完成局部更新后同步签名，阻止 `SpatialDock::commit()` 再次销毁整棵 FX 控件树。保留外部删除、启用状态改变的结构刷新；确需重建时恢复滚动位置与抗锯齿 / 清晰化折叠状态。
- `src/hover_help.hpp`：统一插件提示控制器。保留一秒延迟，使用 OBS 所属窗口内的普通不透明 QLabel 显示说明，限制边界，不创建 `QToolTip` 原生窗口。切换应用、窗口失活、滚动、点击、键盘输入、隐藏目标时取消等待并收起提示。最后一个插件 UI 销毁时同步移除应用事件过滤器。
- `CMakeLists.txt`、`src/plugin.cpp`、`src/dock.cpp`、`installer/setup.cpp`、`installer/setup.rc.in`：统一版本 3.6.5。
- `tests/fx_panel_ui_tests.cpp`：新增滚动、控件身份、外部删除、AA 互斥、提示边界、失活取消、控制器销毁测试；发生异常时输出真实调用栈。
- `tests/v361_ui_bridge.inc`、`tests/v365_acceptance.py`：隔离 OBS 的滚动值、悬停窗口、截图与真实 FX 输出专项检查。
- `README.md`：更新下载版本及本版报告入口。

## 排查证据

旧实现把每个 FX 的启用状态纳入重建签名。本地复选框更新之后，提交再次刷新 FX，连同正在操作的控件一起销毁。新增基线测试观察到 `widgetAlive=0`，测试 FAIL；该最小 Qt 场景中的滚动值仍为 16018，未伪称已在该场景复现跳到零。

旧悬停实现使用 `QToolTip::showText()`，并在 FX 延迟创建参数时重复安装控制器；没有应用失活取消。基线 Windows 测试确实观察到原生 tooltip 窗口，矩形 `663,499 373x0`。用户描述的整个桌面白蒙版本轮未稳定复现，不能把原生窗口记录等同于已经捕获该蒙版。修复直接移除此桌面提示窗口路径。

首次增加统一控制器清理时，关联测试捕获 QApplication 销毁后的 `QObject::removeEventFilter` 崩溃。修正根控件销毁回调和应用空指针检查后，最终四组测试及真实 OBS 正常退出均通过。早期失败日志保留在证据包。
