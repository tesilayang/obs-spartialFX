# v3.4.2 FX 修补开发记录

日期：2026-11-12。版本继续为 3.4.2。本次为本地覆盖更新，交付目录为 `dist/v3.4.2-fxpatch-20261112/`。已发布 Release 的原安装包、源码快照和说明书保持原样。

## 修复内容与计算约定

### 调色曲线改为五参数色阶

保留原入口名称，参数改为输入黑、输入白、输出黑、输出白、伽马值，另保留 RGB／红／绿／蓝通道选择。五个连续参数使用 0.01 步进。

令输入为 v、输入黑白为 ib/iw、输出黑白为 ob/ow、伽马为 g：

```
t = clamp((v - ib) / max(iw - ib, 0.000001), 0, 1)
output = ob + (ow - ob) * pow(t, 1 / max(g, 0.1))
```

输入黑白决定保留的输入区间，伽马调整中间调，输出黑白决定亮度端点。输出黑和输出白均为 0 得到纯黑，均为 1 得到纯白；素材 Alpha 保留。输入黑达到或超过输入白时按阈值切分，不除零；输出黑大于输出白允许反转。

按用户确认保留基础颜色公式：曝光为 `RGB × 2^EV`，范围 −5～5；Gamma 为 `RGB^(1/Gamma)`，范围 0.1～4。曝光 −5 是原亮度的 1/32，+5 是 32 倍；Gamma 改变中间亮度。它们不承担端点强制填充纯色，纯色由色阶输出黑白控制。

旧曲线的输出黑、输出白保留为新输出端点；中间节点拟合新 Gamma，输入区间默认 0～1。旧阴影／高光两个内部节点无法由单个 Gamma 完整表达，迁移只作近似。保存后写入新参数名，保留效果启用状态、强度和通道。

### 环境色受光

旧实现把参考 RGB 以约一半比例混入主体，导致纹理对比减弱。新实现先对参考画面做连续高斯模糊，再生成 16×16 的平滑低频色场。参考只提供色彩比例，不把其图案贴到主体上。

主体 RGB 按参考色彩比例调制，再恢复主体原亮度；围绕原亮度压缩超出色域的色差，保留主体原始 HDR 峰值。染色量 0 严格旁路，透明度保持。参考模糊仍使用“参考采样画面像素”，保留既有参数数值约定；该单位已写入悬停提示。

### 背后柔光与 XYZ

旧实现按半径取 9 个间隔 Alpha 点，大半径形成数层平移轮廓。新实现复用连续分离高斯 Alpha，结合边缘梯度、局部点光方向及距离衰减，生成内部边缘受光与外侧柔和光晕。光晕按预乘 Alpha 合成，增益 0 保持原图。

单一偏移改为背光 X、Y、Z。原点为裁剪后素材中心，X 向右、Y 向下、Z 正值在背后；单位为原素材像素。材质处理后随 `evaluateSceneAt()` 求值的图层位姿运动，不改舞台主灯绑定公式。原素材尺寸与最高 2048 的捕获纹理尺寸分开传递，半径在捕获边界换算。坐标合同已同步记录。

旧 offset 近似映射到 X=`offset×0.832050294`、Y=`offset×−0.554700196`，Z 默认 200；radius、gain、scale 和颜色保留。新光照模型的外观需要按实际素材微调。

### 多组累加显示

组图标独立控制自己的子功能面板。新点亮的组追加到底部，已有点亮的组持续显示；关闭一个组只折叠该组并暂停该组处理。重新点亮追加到末尾。`group_order` 按图层实例保存，重建及重启恢复；旧工程无顺序字段时按原分类顺序补齐。

### 着色器与资源

实际 GPU 测试发现 OBS 的纹理依赖解析早于 D3D 的死代码消除，同组环境色与柔光纹理可能串槽。FX05 在交给 OBS 前剔除其他子功能的分支，保证各自只带入所需纹理。对应单测覆盖分支选择、嵌套花括号及无效输入，GPU 验证覆盖整组效果。

环境模糊、低频色场、背光模糊使用各自缓存；关闭对应效果释放资源。渲染线程不等待 UI。开发期间曾出现 HLSL 保留字造成的编译失败，失败证据保留在 `green-gpu.log`；交付只接受最终载荷的通过记录。
