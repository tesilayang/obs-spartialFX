# OBS Spatial FX 使用说明书

固定版本 v3.4.1 · 中文 · 2026 年 11 月 11 日

把 OBS 的素材分成前景、人物和背景，再让镜头动起来。本说明从“第一次打开”讲起，最后列出全部 13 组、95 个 FX 子功能与参数。

**先记住四件事：选对对象 → 选对时间 → 改数值 → 记录关键帧。** 没有开启的特效不会自动参与处理；一开始不需要把每个开关都打开。

## 01 · 这是什么，哪些图是真截图

这是嵌入 OBS 的 Windows x64 插件。主要工作区有“镜头与动画”“灯光”“FX 特效”“预设”四页。它处理二维素材在三维空间中的平面关系，常称为 2.5D：有远近、有遮挡、有运镜，但不会把一张照片变成完整三维模型。

“舞台”是插件创建的 OBS 来源，负责合成导入的图层。OBS 场景还可以有未导入的其他来源；它们不属于此舞台的动画和 FX 管理范围。

本书标有“真实截图”的图片来自 v3.4.1 已留存的 OBS 33.0.1 界面与 GPU 测试。测试图使用有意设计的色块、斜线和透明区域，便于观察变化，不代表成品直播场景。界面截图中的数值是当时测试状态，**不是全部参数的默认值**。

标有“HTML 操作示意”的交互动画只帮助理解关系，不是插件运行截图，也不是 OBS 的性能测试。颜色、阴影和运动比例为讲解简化，最终效果以自己的 OBS 预览为准。点击真实截图可放大，按 Esc 关闭。

## 02 · 安装、打开、升级与卸载

1. 下载 `OBS_Spatial_FX_V3.4.1_Setup.exe`。关闭所有 OBS 窗口，包括便携版和后台残留的 OBS 进程。
2. 双击安装器，按提示安装。系统插件目录为 `C:\ProgramData\obs-studio\plugins\obs-spatial-fx`。安装器不把插件写入 Program Files，也不打包 OBS 自带 Qt DLL。
3. 常规版按平时方式启动 OBS。便携版使用安装器创建的便携启动入口；仅双击原来的 obs64.exe 不一定采用相同的插件搜索设置。
4. 在 OBS 的“停靠窗口”菜单打开“OBS Spatial FX”。若菜单没出现，先查 OBS 日志中的插件加载信息，确认 OBS 与插件都是 x64。
5. 选中要编辑的 OBS 场景，在 Dock 顶部选择已有舞台，或点“新建舞台”。切换舞台会切换其独立配置。

覆盖升级也要先关闭 OBS。个人场景与预设不是通过重新安装来清空的。建议在升级前导出自己的 OBS 场景集合，另存个人预设和外部媒体。

卸载可从 Windows 控制面板“程序和功能”找到 OBS Spatial FX。**卸载前先在插件中“还原全部”导入图层，再保存场景。** 否则原素材可能仍被隐藏，而舞台来源在卸载后无法加载。安装/卸载不是撤销工程编辑的办法。

目标环境为 Windows 10 1909+ / Windows 11 x64、OBS 32+。实际验证范围与性能限制在本书末尾列明，后续 OBS 版本仍需回归验证。

## 03 · 十分钟做出第一个镜头

1. 在普通 OBS 场景中放好两三项素材，例如背景图片、透明人物 PNG、前景。窗口捕捉也可以，只要它在 OBS 中已经能正常显示。
2. 新建 Spatial FX 舞台，进入“镜头与动画”，展开“导入 OBS 图层”。在场景素材列表选择一项，点“导入选中”。多项可按 Ctrl 或 Shift 选择。
3. 导入会暂停并回到 0 秒。先选中人物图层，调整 X、Y 和缩放，使它在画面中摆好。选背景时把 Z 设得比人物大一些，选前景时把 Z 设得小一些。数值只是起点，结合 OBS 预览调整。
4. 在对象下拉框选择“摄像机”。确保处于动画预览状态，0 秒时点击“记录”，留下起点。
5. 把播放头秒数输入为 3，开启“◆+ 自动关键帧”，再把摄像机 X 从 0 调到 100。也可以先在 3 秒记录，再改数值。
6. 点回到开头，再点播放。看前景与背景在镜头横移时是否移动得不同；若所有素材都在同一个 Z，远近差就不明显。
7. 只想加一个特效时，去 FX 页点“＋”，选已导入的人物实例，点击大组图标，再勾选一个子功能。从低强度试起。
8. 完成后正常保存 OBS 场景。插件更改会应用到舞台来源设置，并触发 OBS 配置保存；媒体文件本身不会被打包进场景。

别先批量打开全部灯光和 FX。先完成一个能播放的简单镜头，再增加效果，这样更容易知道哪一步改变了画面。

## 04 · 导入素材、选对象与整理图层

@@SHOT_IMPORT@@

| 控件 | 怎么用 | 对工程的影响 |
|---|---|---|
| 导入 OBS 图层折叠按钮 | 点箭头收起或展开选择区 | 只改变界面占用，不关闭图层或动画 |
| 当前场景、素材列表 | 选择当前 OBS 场景中的已有来源项 | 不是从磁盘创建新媒体；素材内容仍由 OBS 来源提供 |
| 导入选中 | 选好一项或多项后点击，也可双击素材 | 创建可独立编辑的时间轴实例，并隐藏原项以免重叠 |
| 导入场景 | 导入当前场景的可用视频素材 | 导入后到 0 秒，便于直接布置初始位置 |
| 移除实例 | 在时间轴选一个已导入图层再点 | 删除该实例及其动画；最后一个同源实例移除时恢复原项可见性 |
| 还原全部 | 结束舞台对这些素材的管理 | 全部导入实例及对应动画移出管理，恢复原项导入前可见性 |
| 对象下拉框 | 选择摄像机、全画面合成或某图层 | 只切换编辑目标，不跳时间 |
| 时间轴图层名称拖动 | 拖到其他图层前后 | 改管理与同深度顺序，不替代 Z 的空间深度 |

同一个素材可以反复导入。比如同一张星星图导入三次，就能让三颗星各自运动、各自加 FX。它们共享 OBS 原始来源画面，因此更改原图片路径或窗口捕捉目标会同时改变这些实例的素材内容；位置、动画、透明度和 FX 则分开保存。

图层按独立实例身份关联。改名或拖顺序不会让灯光绑定到同源的另一项。最多 32 个导入图层。窗口捕捉能否读取最小化窗口、受保护窗口或高权限程序，仍取决于 OBS 捕捉方式和 Windows 权限。

“移除对象”位于复位与撤销附近，作用也是移除当前图层实例，会先要求确认。它不能通过运动撤销恢复；误删后可以重新导入。摄像机、全画面合成不能移除。导入区的“移除实例”是另一处入口，不要把它与“删除帧”混淆。

## 05 · 空间位置、镜头和图层属性

画布中心对应世界参考原点；X 正数向右，Y 正数向下。默认摄像机在 `(0, 0, -1500)`，朝 +Z 看，所以默认镜头下 Z 越大通常越远。镜头旋转后，要按镜头与对象的实际关系判断远近，不能永远把屏幕左右理解成世界左右。

所有输入框编辑的是同一套空间数值。灯光绑定、结构图与动画共用空间求值规则。世界单位在任意镜头下并不总等于一个屏幕像素。

| 参数 | 直白解释 | 范围或注意点 |
|---|---|---|
| 位置 X / Y / Z | 把对象往左右、上下、远近移动 | 滑条 −2000～2000；框内可输入 −100000～100000；步进 0.01 |
| 旋转 X / Y / Z | 翻仰、左右转、画面内转动 | 滑条 −360°～360°；框可输入更大圈数；三轴顺序为 Rz × Ry × Rx |
| 水平 / 垂直缩放 | 1 是原大小，0.5 是一半，2 是两倍 | 负值可镜像；缩放不是空间 Z 距离 |
| 等比缩放 | 改一轴时同时改另一轴 | 两轴都要满足解锁和当前关键帧编辑条件 |
| 不透明度 | 1 完全不透明，0 完全透明 | 图层与全画面合成可用；摄像机没有透明度 |
| 摄像机垂直视野角 | 大角度看得更广，小角度画面更紧 | 10°～140°；改变它不是把镜头物理位置前移 |
| 目标 X / Y / Z | 摄像机要对准或环绕的点 | 需要相应约束开关才会驱动镜头 |
| 相机看向目标 | 自动转向目标点 | 俯仰和偏航由计算得出，滚转仍可编辑；不会自动移动位置 |
| 围绕目标移动中心 | 用半径与两个角度控制摄像机位置 | 勾选后 XYZ 只读；未勾选时环绕参数不起作用 |
| 环绕半径 / 水平角 / 俯仰角 | 离目标多远、绕到哪一侧、从多高看 | 仅摄像机有此组；第一次切换按现位置反算，避免立即跳动 |
| 全画面合成 | 最后整体缩放与淡入淡出 | 不改变世界距离、灯光锚点或焦平面 |

自由位置与环绕是两种位置控制方式。已有运镜后切换模式不是无损转换；旧模式曲线会保留并停用。先在副本场景试切换，再继续编排。

### 图层的额外属性

| 控件 | 实际用途 |
|---|---|
| 显示此空间图层 | 控制本实例是否显示，不等于删除原 OBS 来源 |
| 启用此素材 | 控制该管理项是否参与舞台处理；区别于删除实例 |
| 深度顺序 | 同一空间深度下解决谁在前；深度不同仍优先受实际 Z 关系影响 |
| 透视 / 视差倍率 | 0 减弱为参考平面关系，1 正常，接近 2 加强远近差；默认视角有大小补偿，静止时未必明显 |
| 景深模糊倍率 | 0 本层不模糊，1 正常，最大 4；只在离焦且舞台景深启用时明显 |
| 焦平面距离 | 哪个距离保持清晰；这是舞台共用设置，不是每层独立焦平面 |
| 景深强度 / 像素 | 0 不虚化，最大 20；配合层景深倍率、离焦距离和舞台灯光开关 |
| 受光 | 允许舞台灯光改变本层亮度与颜色 |
| 投影 | 允许本层 Alpha 轮廓向其他层投出简化阴影 |
| 接收阴影 | 允许本层作为阴影接收面，还需灯光接收层选择匹配 |
| 轮廓光 | 允许舞台灯光作用于本层透明边缘 |
| 一键恢复选中素材默认状态 | 进入确认复位，恢复导入时的运动状态并清除本层动画 |

同一 Z 的素材一起移动，看起来就像一张平面图。想要视差，先分远近，再动镜头。给背景加 Z 后画面初始大小可能因导入补偿而相近，这不代表 Z 没生效。

### 结构预览与浮动

斜向结构预览用于看摄像机和图层的相对关系，不是视频播放器。展开、折叠只改变界面。可浮动的结构/编辑区域能单独展开；关闭浮窗后返回原 Dock 区域，不会删除对象或配置。Dock 本身也可使用 OBS 的停靠与浮动机制。空间最终画面请看 OBS 主预览。

## 06 · 时间轴：先选对象，再选时间

时间轴横向是秒，纵向是对象与参数。默认显示 0～6 秒，**这不代表动画只能做 6 秒**。最长关键帧决定播放终点；缩放视窗不会改动画长度。

| 操作 | 结果 |
|---|---|
| 点对象名称或参数行 | 激活编辑目标；不会改变播放头 |
| 点对象左侧三角形 | 展开或折叠参数轨 |
| 点菱形 | 选择关键帧；汇总菱形对应同对象同时间的多项参数 |
| Ctrl / Shift 点帧、空白框选 | 多选关键帧 |
| 拖选中关键帧 | 整批改时间；发生已有帧冲突时整次取消 |
| 双击轨道空白 | 在该时间记录关键帧 |
| Ctrl+C / Ctrl+V | 复制选帧；以播放头为起点粘贴，冲突或锁定时拒绝 |
| Delete / 删除帧 | 删除选帧；没有选区则删当前对象或参数在播放头上的帧 |
| Ctrl+滚轮 | 缩放时间轴 |
| 中键拖动 / Shift+滚轮 | 水平平移时间视窗 |
| 普通滚轮 | 上下看对象与参数轨 |
| 适配内容 | 把已有关键帧放进可见时间范围 |
| 显示当前时间 | 把播放头带回可见范围 |

时间输入框以秒为单位，可直接输入 2.5。帧吸附按 OBS 实际帧率计算；音频预打点可以保留子帧时间。动画没有预设的剪辑片段长度，但仍受计算机内存、配置大小和内部数值范围约束。

### 时间轴下方按钮

| 按钮或开关 | 你需要知道的事 |
|---|---|
| 记录 | 选参数行只记该参数；选对象行记录可用位置、旋转、缩放、透明度等。已有同时间帧会更新 |
| 删除帧 | 删除运动记录，不删除素材；可运动撤销 |
| 上一关键帧 / 下一关键帧 | 选参数时只查它；否则查当前对象所有曲线 |
| 锁定关键帧位置 | 禁止已有帧改时间；仍可改值、改缓动、新增或删除 |
| ◆+ 自动关键帧 | 默认关闭。开启后在非 0 秒改值会自动记录，并保留 0 秒初值 |
| 播放 / 暂停 / 回到开头 | 播放所有对象；暂停留当前画面；回到开头定位 0 秒但不删数据 |
| 编辑基础布局 | 看和改静态基础值；取消后按当前时间预览曲线。不会把插值结果偷偷覆盖成基础值 |
| 锁定对象 | 保护当前对象运动参数和曲线；继续显示和播放，不会把灯光与 FX 一起锁住 |
| 循环 | 到最晚关键帧回 0 秒再播；关闭时到终点停止 |
| 速度倍率 | 同时改变各对象动画预览速度，不改已保存关键帧秒数；媒体联动时以媒体 100% 时间为准 |
| 复位当前图层 | 确认后恢复导入默认运动状态并清除本层动画；保留素材关联、顺序、灯光绑定 |
| 复位所有图层 | 确认后处理所有未锁定图层；不重置摄像机与全画面合成 |
| 移除对象 | 确认后移除实例及动画；运动撤销不能恢复它 |
| 撤销 / 重做 | 恢复运动编辑，包括整次拖帧、曲线修改、复位或节拍写入；不覆盖后改的灯光与 FX |

所有图标都可悬停约 1 秒看功能气泡。对象锁与位置锁不同：前者阻止该对象的运动编辑，后者只防止关键帧时间被误拖。

## 07 · 参数编辑与关键帧曲线

每一行参数旁的动画开关，控制该参数是否按曲线播放。◇ / ◆ 表示当前时间没有 / 已有帧，点击可记录。左右小箭头跳到该参数前后帧。关闭某参数动画时用静态基础值，已保存的关键帧仍保留。

自动关键帧关闭时，已启用动画的参数在非 0 秒、又没有关键帧的位置，通常不能直接改值。先点菱形记录，或打开 ◆+。未动画参数仍可改基础值。正在播放时编辑参数会暂停。

最稳的第一次练习：0 秒选摄像机 X，记录数值 0；3 秒记录后改为 100；回 0 秒播放。成功后才添加其他参数。若从对象汇总行记录，会一次记录更多参数，不要把这些重叠菱形当成重复错误。

### 曲线怎样才会出现

1. 选对对象，进入“关键帧 / 曲线”。
2. 在“参数”下拉选择一个确实有关键帧的参数，名字旁的 ◆ 可以帮助辨认。
3. 至少需要两个不同时间点，才有两点之间的可调区间。只有一个点没有运动区间。
4. 选区间或关键帧。选最后一个关键帧时可编辑前一区间。
5. 修改插值类型。需要自己拉速度变化时选“贝塞尔”，再拖圆形手柄或展开手柄数值。

| 插值 | 通俗效果 |
|---|---|
| 线性 | 匀速从前一个值走到后一个值 |
| 缓入 | 从前一帧慢慢起步 |
| 缓出 | 接近后一帧时逐渐减速 |
| 缓入缓出 | 起步慢，中间快，结束再慢 |
| 保持 | 维持前值，到了后一帧才突然切换 |
| 贝塞尔 | 自己控制离开前帧与接近后帧的速度，也可做有限超越 |

曲线横轴是秒，纵轴是所选参数的真实单位。选中关键帧后，“秒数”改时间，“数值”改位置或角度等；不是统一的 0～1 强度。位置锁开启时仍能上下改值，不能横向改时间。

出点 X 与入点 X 用区间时间百分比表示，0% 是前帧，100% 是后帧；出点不能晚于入点，避免时间倒流。出点 Y 和入点 Y 是参数实际值，不是倍率。拖动时按 Esc 可取消，松开后整次可撤销。

旋转“保留圈数”时，0°→360° 是一整圈；“最短路径”会选较短转向，例如 350°→10° 只转约 20°。想要持续转圈时用保留圈数，不要只比较最后画面角度。

## 08 · 灯光：照谁、放哪、跟谁走

@@SHOT_LIGHTS@@

舞台顶部“启用舞台灯光”默认关闭，它管理灯光页的舞台光照、空间阴影与轮廓光。**FX 页“受光与阴影”组的独立附加光源不需要依赖它。** 摄像机和图层几何动画也不依赖这个开关。

1. 打开舞台灯光，选择或添加一盏灯。最多 4 盏；点光源与简化面光源共用数量限制。
2. 勾选“启用所选灯光”，先调位置、范围和强度，确认本层“受光”已打开。
3. 想看阴影时，前景开启“投影”，背景开启“接收阴影”，灯光开启 Alpha 软阴影，并选对接收层。
4. 想让灯跟人物走，选择“灯光绑定素材”。绑定后 XYZ 表示相对该实例的局部偏移，动画、旋转和缩放都会带动灯。

| 控件 | 用途与调节办法 |
|---|---|
| 添加点光源 / 添加面光源 | 点光从一个位置发光；面光用尺寸近似扩展，不是完整三维实体灯具 |
| 所选灯光 / 删除选中灯光 | 先确认下拉选中哪盏，删除只影响这盏灯；添加和删除按钮同一行 |
| 启用所选灯光 | 控制是否照明；不等于灯光实体可见 |
| 光源在画面可见 | 显示灯光可视标记/光斑；关掉仍可继续照明 |
| XYZ / 深度 | 灯的位置；未绑定是世界坐标，绑定后是局部偏移 |
| 灯光颜色与色块 | 选择照明颜色，旁边显示当前颜色；灯光页颜色确认后应用 |
| 强度 | 0 没有直接照明；最大 10；先从小值增加，避免画面过曝 |
| 范围 | 光能影响多远；10～100000，太小可能根本照不到图层 |
| 环境光 | 给整体最低亮度补光，0～2；过高会让阴影不明显 |
| 灯光尺寸 | 0～2000，改变面积/半影近似；不是素材缩放 |
| 距离衰减指数 | 0.1～8；越大通常随距离变化越快 |
| Alpha 软阴影 | 按投影素材透明轮廓求遮挡，需要可接收阴影的另一层 |
| 阴影不透明度 / 阴影颜色 | 0～1 调遮光强度；黑色普通遮挡，彩色为有色透射近似 |
| 软阴影半径 | 0～300，柔化阴影边缘；太大可能失去轮廓 |
| 轮廓光强度 | 0～5，配合图层轮廓光开关 |
| 轮廓光宽度 / 柔和度 | 宽度按源像素，柔和度 0～1；需要有透明轮廓才容易看到 |
| 底层受光 / 阴影接收层 | 选择指定实例，或全部已开启接收阴影的层；不是按素材名字模糊匹配 |

绑定跟随的是动画求值后的图层空间姿态。XY 局部偏移随图层缩放，Z 偏移保持局部世界单位；全画面合成缩放不会反向改变灯光世界位置。移除绑定目标后应重新选择，不能指望自动绑到同名素材。

阴影是按平面深度和 Alpha 简化计算的，不知道人物脸的真实三维法线。完全不透明的矩形只有矩形外轮廓；透明人物、镂空前景和有间距的背景更容易看出效果。不要把平面近似当作真实光线追踪。

## 09 · FX：先加素材，再开大组和子功能

@@SHOT_FX@@

FX 初始是空白的。点“＋”，选择已经在当前舞台时间轴中的图层。每张素材卡片有 13 个大组图标，悬停看名字和说明。

1. 点大组图标：图标变色，该组开启并展开。
2. 勾选子功能：参数展开，开始处理。只打开组、不勾子功能不会得到效果。
3. 先调一个参数，看 OBS 主预览，再调另一个。共同的“混合强度”在 0～1 之间，0 保留原画，1 完整使用效果。
4. 再点组图标会暂停这一组，参数保留；取消子功能勾选会停用它。画质页的“抗锯齿/清晰化”小折叠标题只收界面，**不会停用已经勾选的子功能**。
5. 素材卡片右上 × 会确认移除该实例全部 FX，保留时间轴素材与运动关键帧。

多个效果按插件内部顺序处理，不是可任意拖动的滤镜栈。素材上的某个效果可能改变后续效果输入；排查时一次只启用一个，再逐个叠加。自动运动组作用于图层空间，与像素滤镜和最终舞台裁切的处理阶段有区别。

“受光与阴影”特效组效果独立，子功能需要的附加光源会独立于灯光页主灯单独生效。存在启用舞台灯时，对应效果也会使用场景灯空间关系；没有时使用随素材的局部附加灯。看到效果太弱先检查图层 Alpha、中心位置、尺寸、强度和混合强度，不要只反复切舞台主灯。

### 颜色、辅助素材和外部文件

有颜色功能的 FX 提供色块/色值与编辑入口。调色对话框改变颜色时会实时反馈到舞台，取消会恢复打开前颜色；确认后保存。双色效果各有起始/终端或主/副颜色，具体用途见功能定义。

辅助素材从当前时间轴实例选取，读取的是其原始素材，避免递归叠 FX。图片纹理可读 PNG、JPG、JPEG、BMP、WebP；LUT 可选 .cube 或对应 PNG。选择后如果报错先检查格式、尺寸与路径，不能把无效文件的无变化误当成算法故障。预设不会自动复制这些文件。

部分参数只在相应模式显示，例如渐变叠加的角度用于线性，XY 比例用于径向。目录会列出这些参数的模式条件；切换模式后原参数可能保留但暂不参与。

## 10 · 抗锯齿、清晰化与几种常用效果

@@SHOT_QUALITY@@

SMAA、FXAA 位于“画质修正 → 抗锯齿”，RCAS 位于独立“清晰化”，都不塞在锐化入口。SMAA 与 FXAA 二选一；切换算法会避免两个同时执行，RCAS 可在其后恢复一点锐度。

资源紧张先试 FXAA，再用约 0.25 的 RCAS。FXAA 可能让细字柔一些；SMAA 依赖额外两个中间图像，1080p 单活动层约增加 19.8 MiB 专用空间。RCAS 不放大分辨率、不凭空生成细节；噪点保护也不是独立降噪。AMD Native AA 因缺少所需完整渲染数据，本版不显示。

抗锯齿处理导入素材当时的像素，无法保证修复之后空间透视变换新产生的锯齿。要比较细字和斜线，先在相同 OBS 输出尺寸看原图与处理后，再看实际渲染丢帧。

@@QUALITY_COMPARE@@

基础模糊的高斯是中心重、边缘轻的柔化；方框是均匀矩形扩散。镜像是边界采样方式，不是第三种模糊算法。“磨砂玻璃”才额外加入折射与颗粒；“镜头散景”按圆盘或多边形光圈扩散高光。请在斜线、高反差小点或文字上比较，纯色块本来就看不出模糊差异。

@@BLUR_COMPARE@@

渐变叠加位于“裁切、遮罩与合成”。纯色用一个颜色，线性用两端颜色、中心与角度，径向用中心、比例和 X/Y 比例形成圆或椭圆；反向交换渐变方向。混合强度决定覆盖原图多少，不会把透明区域凭空变为完整新背景。

LED 演出舞台按灯珠/子像素排列采样原画；间距决定颗粒，填充率决定珠间黑缝，亮度与柔光决定发亮感。它不是随便盖一层网格。21:9 宽银幕作用在舞台最终画布：黑边模式上下不透明黑，透明裁切模式上下透明，保留中间 21:9；**不会修改 OBS 全局输出分辨率**。宽画布无需上下裁切时不会强行制造负边框。

## 12 · 节拍：先有运动，再按音乐加点

节拍功能在“镜头与动画 → 额外功能”内。它帮助按音乐放置时间点，**不会自动设计推镜、摇镜或舞蹈**。一条完全不动的 X 曲线，即使写入一百个节拍关键帧也还是不动。

1. 先给一个参数做出两帧以上的基础运动，例如 0～8 秒摄像机 X 缓慢横移。
2. 刷新已有音频来源，选择 OBS 中含音频的素材。可读取的本地媒体点后台分析；不读取文件时可显式采集接下来 15 秒正在输出的音频。
3. 看检测 BPM 和置信度。与音乐不符时可手工输入 BPM，用半频/倍频修正“把一拍识别成两拍”等情况。安静片段、自由节拍与变化速度音乐可能不准。
4. 选拍长比例，例如 1 拍、1/2 拍、1/4 拍、2 拍、4 拍或自定义，并设置范围、起点偏移与最小秒间隔。
5. 先“预览”：只在时间轴画参考线，不加关键帧、不延长动画。
6. 选择一个具体参数，再执行批量写入，确认后按已有曲线采样。相同时间已有帧保留；可以取消未提交批次，完成后整批一次撤销。

120 BPM 时，一拍 0.5 秒，1/2 拍为 0.25 秒，1/4 拍为 0.125 秒。最小秒间隔会进一步筛掉太密的候选。细分网格是时间参考，不表示每条线都检测到了新的鼓点。

离线分析不播放或重启原素材。实时分析需要来源在输出音频，只观察接下来实际采到的一段。单次分析最长 6 小时，候选最多 100 万，是资源保护，不是普通时间轴上限。大批次保存仍可能花时间。

“联动所选本地媒体预览”默认关闭。打开后，播放、暂停和定位动画会实际控制所选媒体的状态和播放位置；仅支持本地 ffmpeg 媒体、100% 速度，偏移表示媒体在时间轴起点。网络、VLC 或变速源不要依赖它精确定位。先做短片检查首拍与镜头是否对齐。

## 13 · 保存、预设与换电脑

修改会更新舞台来源设置并请求 OBS 保存。正常保存场景集合，才是保留工程的主要方式。不要把关闭 Dock 当作清空工程，也不要靠安装器恢复某次编辑。

@@SHOT_PRESETS@@

“预设”页可选择并应用预设，输入名称后保存当前预设。当前 UI 是“保存/应用”，没有专门的一键导出工程包按钮。预设保存到 OBS 插件配置中的 `presets.json`，包含摄像机、曲线、灯光、FX 和布局；跨场景会按已有图层顺序映射布局，不会自动创建媒体或准确猜出同名人物。

应用前先检查当前已导入的图层数量和顺序，重要工程先备份。把预设给别人时还要分别准备有权分享的图片、LUT 和媒体文件，修复绝对路径。便携 OBS 与常规 OBS 的配置根目录可能不同，复制文件前确认正在运行的配置位置。

建议备份：OBS 场景集合、OBS 插件配置、需要的原媒体、你使用的安装包。源码 ZIP、EXE 和本说明书是软件发布材料，不包含你的私人直播工程。

## 14 · 常见问题：按这张表检查

| 现象 | 先检查什么 |
|---|---|
| 没有 Dock 菜单 | OBS x64、安装路径、是否由正确启动入口启动、OBS 日志加载错误 |
| 看不到新导入素材 | 当前场景与舞台是否选对；舞台来源是否可见；层显示/启用；素材在原 OBS 是否有画面 |
| 一张素材显示两份 | 原 OBS 项是否仍可见；是否有意重复导入了多个实例 |
| 改滑条没有反应 | 当前对象、播放头、对象锁、参数轨锁、是否为派生 XYZ、当前是否缺关键帧 |
| 0～6 秒外找不到帧 | 放大到内容或平移时间窗；6 秒只是默认显示范围 |
| 有两帧却看不到曲线 | 在正确对象和参数下拉选有 ◆ 的参数；确认两帧时间不同，选中正确区间 |
| 旋转 360° 没转圈 | 选择保留圈数，不用最短路径；检查是否实际记录了起终点 |
| 镜头移动没有视差 | 图层 Z 是否不同、是否选摄像机、视差倍率是否非零、是否在播放正确曲线 |
| 景深没有变化 | 舞台灯光、景深强度、层模糊倍率、是否离焦；焦平面上的层本应清晰 |
| 舞台灯不照明 | 主开关、所选灯启用、范围与位置、图层受光；灯可见不等于启用照明 |
| 没有阴影或边缘光 | 投影/接收/轮廓开关、接收层、深度关系、Alpha 轮廓、阴影透明度与柔化半径 |
| FX 什么都没变 | 已添加正确实例、大组启用、子项勾选、强度非零、所需辅助素材/文件有效 |
| 收起小面板后还在耗资源 | 小折叠只收 UI；取消子项或关闭大组才停用效果 |
| 颜色点取消却与预期不同 | FX 调色取消恢复打开前色；灯光页与 FX 页入口不同；也检查其他叠加效果 |
| BPM 不准 / 打点后不动 | 手工校正节奏；打点是采样原曲线，先建立有变化的运动 |
| 窗口捕捉黑屏 | 先脱离插件检查 OBS 本身能否捕捉；目标窗口最小化、权限和捕捉方法 |
| 渲染丢帧增加 | 从少量效果开始，关重复模糊/历史/高分辨率多层；查看 OBS 统计而不是只看平均值 |
