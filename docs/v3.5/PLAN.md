## 模块与接口

- src/project/project_document.cpp（声明位于 project_obs.hpp）：格式、依赖列表、路径修订、验证，独立于 OBS。
- src/project/project_archive.hpp/.cpp：原样复制、ZIP64 写入/ZIP 解包、路径边界、清单校验；不依赖 OBS。
- src/project/project_obs.hpp/.cpp：captureScene(obs_source_t*) -> QJsonObject；restoreScene(QJsonObject,bool) -> ImportResult；所有 libobs 调用在 UI 线程。
- src/project/project_panel.hpp/.cpp：四按钮与双路径导入对话框，后台文件任务及手动重连。
- src/dock.cpp/.hpp：新增工程页并与刷新绑定；保留原预设页。
- tests/project_document_tests.cpp、tests/project_archive_tests.cpp、tests/v35_qa.inc：真实文件及真实 OBS 端到端测试。
