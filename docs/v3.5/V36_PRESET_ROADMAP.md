# v3.6 快捷预设研发保留计划

用户指定在 v3.6 正式实现。本次 v3.5 保留已有预设能力并拆出工程管理页，不增加尚未实现的操作入口。

预期操作：选择已导入时间轴的一个实例，在预设页单击运动、蒙版或转场卡片，将对应参数与关键帧写入该实例时间轴。

正式开发前确认以下细节：

1. 第一批运动、蒙版、转场的具体目录与效果。
2. 应用起点、持续时间、重复/反向规则，以及与已有参数轨、FX 的合并或替换方式。
3. 预览、应用、撤销和恢复机制；不修改其他实例。
4. 预设格式、外部资产、版本迁移和工程包携带规则。
5. 卡片展示与操作布局。

所有坐标与参数轨继续引用现有统一求值原则，工程管理继续保存对应来源设置。方案确认后再实施、编译、实测和打包。
