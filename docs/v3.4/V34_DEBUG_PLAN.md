# v3.4 修复实现记录（2026-11-11）

授权：按用户列出的五项功能直接修复；版本保持3.4.0，说明书不更新。

1. 对照本地 shaderfilter 与 Horaiken 原始参考，区分高斯（距离权重）、方框（均匀权重）、镜头散景（光圈面积）；镜像作为边界策略明确展示。固定采样上限，复用GPU资源。
2. 独立FX受光不应被默认关闭的舞台灯光门控吞掉。有启用空间灯时沿用其位置、绑定及颜色；没有时只在激活该FX的图层使用明确说明的局部效果灯。修正Alpha边界与不透明图层的可见轮廓效果。
3. 移除FX11.1，不重排其他持久化ID。
4. 增加FX12.9渐变叠加，放在混合模式上方；纯色、线性、径向，共用颜色、中心、缩放、柔和度与反向，模式相关参数按需显示。
5. LED改为真实素材按单元采样＋暗缝发光点阵。参考BillboardLive的画面像素化与圆形发光单元原则，提供RGB灯珠及圆点形态。
6. FX13.1作为最终舞台处理，固定中间21:9；黑边不透明、裁切外围透明。用户已确认，不改OBS全局分辨率。多对象启用时按时间轴第一项有效配置决定。

验证：真实OBS32/33、透明素材与不透明素材、核分布、默认灯光/手动灯光、渐变端点/反向/椭圆、LED暗缝与源颜色、最终画布21:9、关闭恢复、资源复用、旧配置升级及安装保护。
