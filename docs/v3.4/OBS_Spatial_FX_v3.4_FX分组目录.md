## 使用与合并规则

1. 第一层只显示 13 个大功能。进入后再看类型、模式与参数。
2. 互相替代的算法用模式选择，例如高斯／方框、内描边／外描边。可以叠加的效果保留独立开关，例如锐化与降噪。
3. 同类参数共用位置、范围、强度等基础控件，只有选中具体模式后才显示其专用参数。这是后续界面建议，本轮只确认目录。
4. 组合预设调用前面的大功能，不再重复建设一套模糊、辉光或抖动。
5. 待定项仍标待定；排除项不返回主目录。

## FX01 · 画面模糊

让画面变柔、虚化、拖尾，或用像素块遮挡细节。

| 子选项 | 作用与模式 | 原选择 |
| --- | --- | --- |
| 基础模糊 | 同一个选项里选择高斯或方框：高斯更柔顺，方框更均匀。 | L074 需要；L039 需要 |
| 磨砂玻璃 | 像隔着毛玻璃看画面，适合局部遮挡或文字底板。 | L011 需要 |
| 径向模糊 | 保留中心附近清晰，让周边逐渐模糊。 | L024 需要 |
| 方向拖线 | 沿指定方向把画面细节拉成模糊线。 | N001 需要 |
| 镜头散景 | 让失焦高光变成圆形或多边形光斑。 | N002 需要 |
| 条带移轴 | 保留一条清晰带，两侧逐渐模糊，形成微缩模型感。 | N003 需要 |
| 运动模糊 | 依据可获得的运动信息，模拟物体运动产生的拖线。 | N004 需要 |
| 残影拖尾 | 把之前的画面少量留下，让运动出现一层层拖尾。 | L084 需要 |
| 像素化 | 同一入口选择规则方块或不规则晶格。 规则马赛克/像素化待定；不规则晶格已选。 | L018 待定；L113 需要 |

### 本组整理要求

- 按你的要求，将磨砂玻璃与其他模糊、像素化效果合并为“画面模糊”。
- “中心清晰周边虚化”改名为“径向模糊”。该模式是中心清楚、周围逐渐虚化；不含你已排除的缩放放射拖线模糊或旋转模糊。
- “马赛克与像素化”仍标待定；已选中的不规则晶格像素化保留，不因同组而一起改成待定。
- 散景模式可作为 FX13 舞台装饰光斑的共用处理能力；不要求用户筛选两次相同的虚化算法。
- 按运动方向计算的模糊保留为候选，但普通视频本身没有完整运动矢量；后续先评估使用插件已知图层运动估计，不能据本目录宣称已实现。

### 你的原始备注

- **L011 · 磨砂玻璃：** 和其他模糊/像素化类的效果合并，作为其中子效果之一，功能改为”画面模糊“
- **L024 · 中心清晰周边虚化：** 改名为径向模糊
