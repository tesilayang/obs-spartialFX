# OBS Spatial FX v3.4 · FX 候选清单

研究日期：2026-11-10。用途：先挑效果，再决定 v3.4 的开发范围。以下条目不是已经交付的功能。

## 怎么看

先看“去重后的效果目录”。每项都有编号、通俗解释、可调参数和限制。`L` 是本地效果/工具，`T` 是双画面转场，`N` 是两组本地实现未覆盖的社区补充，`D` 是模板、内部文件或未完成实验。

你可以用编号回复，例如“L004 要横向光带，不要黑边；N005 需要；N021 待定”。也可以打开同目录 HTML，在每项选择“需要 / 待定 / 不需要”，写备注后导出选择 JSON。选择记录只保存在当前浏览器的本机存储；文件转移或更换浏览器请导出备份。

## 去重与判断规则

1. 字节完全相同才叫“完全重复”；同名但代码不同保留为变体。
2. 同一种视觉目的的多个实现合并：如高斯模糊的 simple、advanced、LOD；保留质量和遮罩等差异。
3. 组合预设保留整体名称，同时注明内部模块重叠：宽银幕、演出舞台、醉酒效果都属于组合。
4. 单素材滤镜、背景生成器、双源混合、A/B 转场和诊断工具分开说明用途。不能把转场直接当普通单图层滤镜。
5. 依据实际代码与参数解释，不只翻译文件名。未完成模板及疑似实现缺陷单独标记，不承诺可直接使用。

## 与当前 v3.3 的关系

现有 FX 页面已包含：曝光 EV、饱和度、图层暗角、焦点距离、景深强度。镜头与动画已有图层位置/旋转/缩放/透明度及摄像机功能；灯光已有点/面光、绑定、漫反射、投影与轮廓光入口。

因此基础曝光/饱和度/暗角/推拉/空间透视不当作全新功能重复建设。更细的遮罩、调色和镜头光学可以扩展现有模块。二维投影、轮廓描线、受灯方向影响的 Rim Light 含义不同，应避免在 UI 上叫成同一个东西。本轮只记录现有入口，不重新判定其画面质量。

后续如果开发，所有图层/灯光/摄像机继续共用现有空间坐标，FX 默认关闭；先确定作用于“当前实例 / 全画面 / 辅助源 / 转场”，再决定参数及关键帧。这里属于建议，尚未锁定 v3.4 范围。

## 去重后的效果目录

“建议参数”是选型说明，并非承诺每份现有脚本都有这些控件。原文件实际字段另见完整索引。普通条目均为静态源码判读，运行效果与性能均 **NOT RUN**。


### 立体与运动


#### L001 · 立体厚面板 / 3D Panel

- **看到什么：** 把平面素材变成带厚度、圆角和侧面的卡片，旋转时能看见侧边，适合立体直播框。
- **建议参数：** XYZ 旋转、位置、厚度、圆角、缩放、侧光、摇摆
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 日文版、中文版和 shader 实现归为一项；部分 Lua 版本另有背面贴图。不是任意三维模型。
- **对应文件或依据：** Lua：Horaiken3DPanel/Horaiken3DPanel.lua；Horaiken3D面板/Horaiken3D面板.lua；shader：3d-panel.shader

#### L002 · 轮廓挤出块 / 3D Block

- **看到什么：** 沿透明素材的实际轮廓挤出厚度，让头像、文字像立起来的实体标牌。
- **建议参数：** 厚度、XYZ、缩放、背面贴图、左右侧光、摇摆
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 与 L001 的矩形卡片不同，厚度跟随 Alpha 轮廓。
- **对应文件或依据：** Lua：Horaiken3DPanel/Horaiken3DBlock.lua

#### L014 · 分层镜头晃动视差 / Horizon Camera

- **看到什么：** 镜头轻微移动时，不同深度倍率的素材移动量不同，产生前后层次的视差。
- **建议参数：** 深度倍率、晃动幅度与速度、边缘扩展
- **作用范围 / 状态：** 摄像机 / 多图层；本地候选。
- **区别与限制：** 两个文件 SHA256 完全相同；本质是分层二维位移，不是完整三维摄像机。Spatial FX 已有摄像机与分层坐标体系，应复用。
- **对应文件或依据：** Lua：HoraikenHorizon/HoraikenHorizon/HoraikenHorizonCamera.lua；HoraikenHorizon/HoraikenHorizonCamera.lua

#### L026 · 随机抖动 / Wiggler / Shake

- **看到什么：** 让整个素材随机上下左右轻晃，适合手持镜头、紧张感或人物呼吸感。
- **建议参数：** 幅度、速度、频率、边缘扩展
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 与分层深度视差 L014 分开；这里不因图层远近自动改变移动比例。
- **对应文件或依据：** Lua：HoraikenWiggler/HoraikenWiggler.lua；shader：shake.effect

#### L027 · 折边摄像头框 / Bent Camera

- **看到什么：** 让摄像头矩形左右两侧像纸片一样折起，并用阴影强调折痕。
- **建议参数：** 左右侧宽度、折边宽度、侧面大小、阴影
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 两个作者版本保留为变体。
- **对应文件或依据：** shader：alpha-gaming-bent-camera.shader、exeldro-bent-camera.shader

#### L035 · 闪烁 / Blink

- **看到什么：** 让素材按节奏明暗或显示隐藏，适合警示灯、提示文字。
- **建议参数：** 速度、点亮时长、熄灭时长
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 平滑闪烁与硬切开关作为两种子模式。
- **对应文件或依据：** shader：blink.shader、hard_blink.shader

#### L052 · 旋转立方体 / Rotating Cube

- **看到什么：** 把一张或多张图片贴在旋转立方体上，可用作节目装饰。
- **建议参数：** 贴图数量、旋转速度、阴影
- **作用范围 / 状态：** 图层 / 多张辅助贴图；本地候选。
- **对应文件或依据：** shader：cube_rotating.shader

#### L072 · 翻转与旋转 / Flip / Rotate

- **看到什么：** 水平或垂直镜像、平面转动，或围绕指定轴做旋转动画。
- **建议参数：** 翻转方向、角度、转速、中心、旋转轴、缩放
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** Spatial FX 时间轴已覆盖基础旋转和缩放；此处整理可用自动循环变体。
- **对应文件或依据：** shader：flip.shader、rotating-source.shader、rotatoe.effect

#### L092 · 呼吸缩放 / Pulse

- **看到什么：** 让素材按节奏周期性放大缩小，像在呼吸或跳动。
- **建议参数：** 速度、最小最大扩张像素
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 当前文件是时间驱动；不是自动跟随音乐节拍。
- **对应文件或依据：** shader：pulse.effect

#### L096 · 图像重复平铺 / Repeat / Tiling

- **看到什么：** 把同一画面按多份或网格重复排列，形成电视墙或图案背景。
- **建议参数：** 副本数、网格、中心裁切、混合与透明度
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 这里只是同一纹理的平铺，不等于时间轴里多个可独立运动的实例。
- **对应文件或依据：** shader：repeat.effect、repeat_grid_center_crop.effect、repeat_texture.effect

#### L115 · 定点缩放 / Zoom

- **看到什么：** 围绕指定中心放大或缩小画面，强调人物或物品。
- **建议参数：** 中心、缩放强度
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** Spatial FX 已有摄像机推拉和图层缩放；应避免同一动作出现多个互相冲突的坐标入口。
- **对应文件或依据：** shader：zoom.shader

#### L117 · 透视旋转 / Perspective Transform

- **看到什么：** 让平面素材按 XYZ 角度倾斜并产生近大远小效果。
- **建议参数：** XYZ 旋转、透视强度、边框
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** Spatial FX 已有空间变换，作为现有功能参考而不是新增第二套坐标。
- **对应文件或依据：** shader：perspective.shader

### 光照与光学


#### L003 · 环境色自适应受光 / Adaptive Lighting

- **看到什么：** 从指定参考画面取颜色和亮度，让人物染上环境色，减少人物像贴在背景上的感觉。
- **建议参数：** 参考源、强度、平滑、亮度、对比度
- **作用范围 / 状态：** 图层 + 参考源；本地候选。
- **区别与限制：** 是采样调色式受光，不等同于根据灯与表面距离算出的物理照明。
- **对应文件或依据：** Lua：HoraikenAdaptiveLighting/HoraikenAdaptiveLighting.lua

#### L004 · 宽银幕镜头组合 / Anamorphic Lens

- **看到什么：** 强光拖出横向光带，搭配色散、颗粒和电影色调，形成宽银幕镜头风格。
- **建议参数：** 光带强度、色散、对比度、颗粒、色调、上下黑边
- **作用范围 / 状态：** 图层 / 全画面；本地候选。
- **区别与限制：** 组合包含与色散、噪点及调色重叠的模块；保留整体预设。源码的 ACESFilm 拟合曲线不是完整 ACES 色彩管理。
- **对应文件或依据：** Lua：HoraikenAnamorphicLens/HoraikenAnamorphicLens.lua

#### L006 · 背后柔光 / Backlight

- **看到什么：** 在人物后方铺一团有颜色的柔光，可带轻微湍动，制造轮廓与背景分离感。

## 没有重复算成“社区新增”的效果

Retro Effects 的像素化、色阶化、抖色、抽帧、CRT 曲面、色散、数字故障，与本地相应家族有交集；只补充本地缺少的 NTSC、隔行扫描和 CRT 开关机。Composite Blur 的普通高斯/方框/缩放模糊也不再新增计数。

普通残影已经由 `motion_blur.shader` 的历史反馈覆盖。低帧持帧已存在于 Manga、RetroGame 等 Lua。Screen/Overlay 已在 Horizon Lens 组合里使用。LUT、色相、噪点、雨窗、Bloom、外描边、外投影都已有本地参考，不能换个英文名就当新增。另补充 Retro Codec/RPZA 压缩外观；它不是数字信号故障的简单改名。

## 暂列研究、不承诺直接接入的效果

| 名称 | 通俗定义 | 缺少什么 / 与本地的关系 |
| --- | --- | --- |
| AO / 环境遮蔽 | 接缝、贴近处自然变暗，使物体更有体积 | qUINT MXAO 依赖真实深度数据；普通 OBS 捕捉不会提供游戏完整深度缓冲。已有图层投影不等于 AO。 |
| SSR / 屏幕空间反射 | 在表面看到画面里其他物体的倒影 | qUINT SSR 依赖深度及表面相关假设；不能仅凭视频像素恢复真实反射。 |
| 像素级深度景深 | 同一张摄像头画面中，人物清楚、前后背景失焦 | 需要额外深度图或估计模型；现有每图层 Z 只能给出层级深度，不是人体逐像素深度。 |
| 三维体积雾与体积光 | 光穿过空气产生可被物体遮挡的立体光柱 | N018/N026 仅能做屏幕空间或分层近似；完整版本要场景几何与深度。 |

## 社区依据与“口碑”的含义

这里的“社区参考”优先选择 OBS 官方资源区有持续发布和实际用户评价的项目；不声称所有项目无差评，也不拿某个项目的总评分给每种算法背书。网页下载数与评分会变化，且评价样本小；本轮不做虚假的全网排名。

- OBS 社区项目（S02–S08、S12）：用实际滤镜的成熟功能作为主要参考，并在 HTML 来源区提供项目入口。
- AMD、Blender、qUINT（S10–S22）：用于补全常见视觉效果及定义；其中 Blender 和 qUINT 是跨软件参考，不等于已有即装的 OBS 版本。
- 每个 N 条目均写明参考与本地缺口；N026 的分层雾、N030 的尘点扩展等包含本项目设计推导，未冒充原项目已直接提供相同实现。

项目开源不表示目录里每个移植 shader 都是同一种许可证。本地个别文件有非商业/相同方式共享条款；Horaiken 文件也不能仅因在合集中就推断统一授权。选定后应逐文件核对许可证，必要时只参考效果独立实现。本次不复制第三方程序代码进插件。
