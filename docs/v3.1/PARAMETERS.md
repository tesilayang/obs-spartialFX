# v3.1 图层参数：作用和实际生效条件

这份说明对应当前实际 C++ 合成与 shader 实现。本次保留三个进阶参数的计算方式，只改善说明及图层 XYZ 滑条。

## 位置 XYZ 滑条

图层 X / Y / Z 滑条固定线性映射 −2000～2000，中央为 0。拖动是选择坐标绝对值，松手后不会重新居中。滑条方向键及数值框微调步长均为 0.01；有限宽度的滑条无法用鼠标逐个选遍 400001 个值，精确数值可直接输入。

数值框保留 −100000～100000 的范围。输入例如 3456.78 后，实际图层坐标仍为 3456.78，滑块停在最右端；刷新、切层不会把真实坐标改成 2000。重新拖动滑条才会回到其 −2000～2000 范围。旋转、灯光及相机等本次未指定的控件保留 v3.0 行为。

## 同深度叠放顺序（原“深度顺序”）

它是遮挡优先级，不是 Z 坐标。渲染先按图层中心在相机坐标下的深度从远到近绘制；仅当两个中心的相机深度完全相等时，才按本项数值从小到大绘制。后绘制的层覆盖先绘制的层，所以同深度时数值越大越靠前。不重叠时也看不到差异。

操作示例：把两张互相重叠的图层放到同一 Z（默认未旋转相机），分别设为 0 和 10；10 在上。交换数值，遮挡交换。如果 Z 不同，本项无法跨过真实深度关系。相机旋转时相机深度也受 XY 位置影响；倾斜或相交的平面仍采用中心排序，并非逐像素三维深度测试。

列表拖动会同时按列表顺序重写各层的叠放序号；它不会修改图层 Z。

## 透视 / 视差倍率

本项调整该层的“有效深度”，不是亮度、透明度或普通缩放。0 把深度压到世界 Z=0 的参考平面；1 保留原深度；2 使有效 Z 加倍。前后方向由 Z 的正负决定，因此 2 不意味着所有层都后退。

具体实现：原图层位置 `(x,y,z)`、缩放 `(sx,sy)` 和倍率 `p`，变为：

    f = (1500 + z*p) / (1500 + z)
    position = (x*f, y*f, z*p)
    scale = (sx*f, sy*f)

补偿以默认相机 `(0,0,-1500)` 为基准。对未倾斜图层，默认镜头下的初始位置和大小基本保持一致；移到侧面、推近或拉远相机时，各层才显示不同的运动幅度。因此只把 1 调成截图里的 0.96，并在默认镜头下静看，通常难以察觉。

操作示例：背景 Z=600，前景 Z=−200，相机 X 从 0 移到 300，比较各层倍率 0 和 1 的相对移动。相机横移时近层移动更明显；所有层倍率均为 0 时，它们处于相同参考深度，差异减弱。

生效与限制：几何参数不依赖“开始光影处理”。Z=0 时改变倍率无作用。当前代码在 `abs(1500+z)<=20` 的退化区跳过补偿；请避免把图层放在默认相机平面附近。倾斜图层、非默认相机下并不保证初始画面完全相同。相机近裁剪深度为 10，移到相机背后的层不会显示。

## 景深模糊倍率

本项是每层的离焦系数，不会自行开启景深。当前每层使用一个由中心深度计算的统一模糊半径：

    radius = min(20, abs(d - focusDistance) / max(d,10)
                     * (FX开启 ? aperture : 0) * focusBlur)

`d` 是该层中心距当前相机的前向深度，focusDistance 是摄像机页的“焦平面距离”，aperture 是“景深强度 / 像素”，focusBlur 是本层倍率。

因此：

- FX 总开关关闭 → 半径 0。
- 摄像机景深强度为 0（默认）→ 半径 0，任意倍率都无效果。
- 图层中心在焦平面上 → 半径 0，仍然清晰。
- 本层倍率 0 → 该层不模糊；1 正常；更大值加重离焦，最终半径上限为 20。

操作示例：相机 Z=−1500、人物 Z=0、背景 Z=600；打开光影处理，把摄像机焦平面距离设为 1500，景深强度设为 20。人物保持对焦，背景离焦。背景倍率由 0 调到 4，对比其文字或网格边缘；把强度恢复 0，全画面重新清晰。

当前使用原像素四倍权重加上下左右四个偏移采样的五点近似，作用于每层原纹理，不是完整镜头光圈散景，也不是逐像素深度模糊。它始终保留 50% 的中心采样，增加倍率主要扩大采样间距，并不保证高频纹理会连续、自然地变柔和，可能出现重影。纹理最长边限制为 2048，OBS 缩小预览、素材本身柔和或倍率变化很小时，差异会更不明显。本次没有把它改成更重的高斯/散景算法，也没有自动开启 FX。
