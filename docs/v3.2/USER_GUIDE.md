# v3.2 镜头与动画操作说明

## 选谁、改什么

时间轴左侧三角展开对象，行名只选择对象/参数，不跳播放头。顶部下拉框也可选相机、全画面或已导入图层。空间列表和结构图跟随图层身份；重命名/排序不会把它换成同源另一实例。

参数页左侧勾选框是该参数的动画启用开关，◇/◆为当前时间没有/已有关键帧，‹/›跳到前后帧。数值滑条与空间页使用绝对坐标和同一求值器。位置XYZ默认−2000～2000，旋转XYZ为−360°～360°，方向键0.01；数值框允许±100000。缩放1=原大小，透明度1=完全不透明；负缩放可镜像。相机没有不透明度，请使用“全画面合成”。

自动打帧◆+默认关闭：无动画的参数修改基础值；有动画时只修改播放头精确时间上已有的帧。若这里没有帧，先点◇/◆记录再修改。开启◆+后，在预览中修改参数会自动打帧，首次非0秒记录会补0秒初值。等比缩放两轴遵守同一规则，任一轴锁定或缺帧时整次不改。关掉“编辑基础布局”进入时间预览；勾选它回到静态基础值。正在播放时编辑参数会暂停。

## 时间轴与曲线

默认视口0～6秒。Ctrl+滚轮缩放，中键拖动/Shift+滚轮/平移按钮移动视口，普通滚轮上下看轨道。⛶缩放到内容，◎让当前时间可见，显示窗口不改任何关键帧。时标长时间以分钟/小时显示，数值输入以秒为准。时间为微秒整数字符串存储，帧吸附按OBS实际帧率；音频预打点保留子帧。

单击菱形选帧，Ctrl/Shift累加选择；汇总菱形选择同对象同时间的所有参数帧。空白区域框选参数帧；拖选区整体平移，遇到已有帧冲突则整次取消。Ctrl+C/V复制/粘贴；Delete或“删除帧”删除选区，没有选区时删除当前参数/对象在播放头的帧。

时间轴下方◀│/│▶定位前后关键帧，选择具体参数时只查该参数，汇总行则查对象全部参数。位置锁禁止已有帧改时间，仍允许改值、缓动、添加或删除；对象锁保护整个对象的编辑。所有说明悬停至少1秒显示。

“关键帧 / 曲线”先选择参数，纵轴为实际单位，横轴为秒，完整显示该参数关键帧及曲线。单击菱形与秒数/数值联动；拖菱形改时间和数值，锁位置后仅上下改值。圆点调整当前区间的手柄，拖动中坐标范围固定，Esc取消，松开整次可撤销。最末帧选中时编辑其前一区间。区间插值包括：线性、缓入、缓出、缓入缓出、保持、自定义贝塞尔。缓入让离开前帧时慢起步，缓出让进入后帧时慢下来。展开“手柄数值”，横向为0～100%区间时间，纵向为参数实际单位；两手柄时间有序，防止时间倒流。数值受参数合法范围限制，图中拖动限定在可见范围，可有限过冲。新旋转轨默认保留圈数，0→360是一圈；已保存最短路径设置保持；350→10按350→370方向插值，切换贝塞尔保持此短路径。

## 环绕与相机

“围绕目标移动中心”仅用于摄像机，改变其中心绕目标的位置，区别于自转。首次切换会从当前坐标反算半径/角度，避免立即跳动；旧自由位置/环绕曲线停用并保留，切换模式并非运动轨迹无损转换。单独的摄像机环绕组只在勾选后生效；图层不显示半径、水平角和俯仰角。环绕时XYZ由目标、半径、水平角/俯仰角派生，界面禁用直接编辑；相机看向目标时俯仰/偏航也是派生值。

相机可编辑位置、旋转、垂直FOV、目标和环绕；图层增加缩放、透明度。全画面合成在渲染末尾做缩放/透明度，不改变空间距离、光源锚点或焦平面。常用镜头见“预设”页的平滑推镜/环绕视差，也可保存个人预设。

播放终点取所有保留关键帧的最晚时间，无旧范围。暂停保留画面，开头跳0秒。循环到终点回0；倍率同时改变所有动画速度，不重写帧秒数，媒体联动以100%媒体时钟为准。图层复位均先弹确认，默认取消。当前/所有图层只恢复导入默认运动状态，保留绑定、排序和灯光设置；锁定图层跳过。相机/全画面有单独确认复位按钮。撤销/重做只恢复运动数据，不覆盖后续灯光和FX修改。

## 节拍额外功能

从OBS已有来源列表选择，分析本地文件不会打断原源；可显式采集15秒实时音频，或手工BPM。黄色拍点是检测结果；低置信度时请人工校正，分拍候选是局部插值网格，不是新检测到的鼓点。

120BPM一拍0.5秒：1/4拍网格约0.125秒、1/2拍0.25秒、2拍1秒。候选以实际首拍/用户偏移为起点，非固定从0秒假设。范围和最小秒数可进一步筛选。先预览，不改变运动长度；再选具体参数，确认批量写入。原曲线插值拆段保轨迹，同时间帧跳过；平坦曲线打很多点仍是平坦，不会自动晃动。

媒体文件/速度/来源或文档变化时，过期分析/后台批次不会覆盖新状态。生成中可取消；整批一次撤销。单批100万候选、分析最长6小时属于明确资源保护，并非时间轴时长上限。超大批次最终提交仍要序列化并保存，可能有可见耗时。

媒体联动是可选的有副作用操作，只支持本地ffmpeg_source、100%速度。选择来源/偏移会重新发布主时钟配置；停止/结束/删除素材时必须检查状态。网络/VLC/变速源仅做实时观察或手工BPM，不承诺定位或同步。先做短片预览确认首拍与镜头时间，再用于实际直播。
