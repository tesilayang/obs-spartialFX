# v3.2 同版本修订 · 2026-11-01

版本保持 **3.2.0**，覆盖原来的v3.2交付文件和系统安装。原安装器、源码、符号和证据包备份在 `work/v3.2-fix/original-release`。V1、V2、V3.0、V3.1发布文件保留原SHA256。

## 实际改动

- 时间轴下方是一排图标工具：上一帧、下一帧、时间位置锁、自动打帧、缩放、显示全部、显示播放头、平移、吸附。前后定位按选中的参数查找；选对象汇总行时查该对象全部参数。
- 自动打帧默认关闭。有动画且当前位置缺帧时，先手工记录再改参数；开启自动打帧后直接生成当前参数的帧。等比缩放的两轴同时检查，避免绕过开关。未动画参数仍修改基础值。
- 时间位置锁禁止改已有帧的秒数及左右拖动，允许上下改数值、改插值、记录和删除。对象锁保护对象全部运动编辑，两者独立，均有详细气泡。
- 删除旧播放范围、隐藏旧摄像机表单、旧整组关键帧桥接与schema1～3自动迁移。播放终点只取当前schema4保留参数轨的最晚帧；已有v3.2参数轨继续保存。
- 旋转XYZ滑条绝对映射−360°～360°、步进0.01。位置XYZ保持−2000～2000，超出范围手工输入。两页共用参数元数据和统一空间求值器。
- 环绕半径、水平角、俯仰角只在摄像机显示，单独分组；勾选“围绕目标移动中心”后启用。图层不显示这些控件和轨道。
- 固定说明搬到本Dock内的一秒延时气泡；基础布局、对象锁、循环、倍率分别说明影响范围。实际进度、错误和当前选中状态仍直接显示。
- 曲线页增加显式参数选择、完整参数曲线、实际时间/数值坐标、关键帧点选择与拖动。数值面板与可见区间统一使用左端出点和右端入点；手柄横轴是时间百分比，纵轴为参数实际单位。
- 拖动固定坐标范围，避免手柄一动就重算视口导致数值跳动。全轨拟合包含所有区间的手柄；手柄时间有序，拖动值与时间限定在合法/可见范围。Esc取消，整次拖动一次撤销。最短旋转使用与求值器一致的有效角度端点。

主要代码：`src/editor.cpp/.hpp`、`editor_timeline.cpp`、新增 `editor_curve_widget.cpp`、`editor_curves.cpp`、`editor_help.cpp`、`hover_help.hpp`；模型/求值与旧桥接清理在 `animation.hpp`、`model.cpp/.hpp`、`scene_evaluator.cpp`、`stage.cpp`、`dock*.cpp/.hpp`。完整逐文件差异见 [MODIFIED_FILES.md](MODIFIED_FILES.md)。测试新增 `tests/v32fix_qa.inc` 和 `tests/v32fix_persistence.py`，扩展动画/模型测试并适配原回归脚本。未改动GPU着色器与共享空间变换原则。
