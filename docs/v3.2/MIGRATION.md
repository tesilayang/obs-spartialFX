# v3.2 配置与迁移

产品版本3.2.0，私有模型schema4。运行状态仍由UI写入不可变快照；禁止改回渲染线程读取obs_source_update的可变公共设置。OBS源私有 spatial_fx_model 保存完整模型。

## 时间和数据

每对象按参数保存 animation 数组，含enabled/locked/shortest与keys。time_us 是64位微秒十进制字符串；没有256帧/3600秒静默截断。全画面参数存 composite，环绕独立保存，基础位姿不由播放覆盖。插值含显式控制手柄、absolute标记；legacy_from/to 保留旧分段三次曲线子区间，音频无损插帧不改变原运动。

2026-11-01修订按用户要求彻底移除schema1～3整组keyframes/motion迁移和旧播放范围。读取时不导入旧整组动画；保存时删除旧字段。播放长度只取schema4保留参数轨的最晚时间。原始v3.2已保存schema4的轨道、手柄、锁、最短路径设置继续读写。

不再生成schema3备份或旧版备份导出；此前已有的备份文件不删除。早期版本工程需使用原安装器和单独场景备份处理，不承诺旧动画自动升级或向旧版降级。当前3.2安装覆盖不清除OBS用户配置和个人预设。

新增auto_key（默认false）和key_positions_locked（默认false）。前者控制参数编辑是否新建帧，后者只保护已有关键帧的时间位置；均随舞台/预设保存。schema4插值中的LegacySmooth/LegacyCubic是已经存入参数轨的数学模式，保留其求值与拆段，不属于已删除的旧工程支持。

## 身份、预设和并发

对象身份由scene UUID / sceneitem ID / source UUID构成。关键帧引用是对象身份+参数+微秒时间，内部瞬时索引在场景/结构改变时清除；后台写入同时核对revision、目标身份、原曲线共享存储和媒体指纹。COW曲线使只读seek不复制10万帧文档。

个人预设保存schema4轨道与环绕/全画面数据，应用时保留当前场景源绑定，灯光关系转为布局槽位后重新关联。图层运动撤销只恢复运动，不回滚之后的光影开关或强度。批次更改可取消并作为一条历史记录。

未来灯光/FX页面必须调用src/scene_evaluator.hpp中的evaluateSceneAt，不重新实现坐标插值或绑定公式。单位和旋转顺序见统一坐标协议。
