# OBS Spatial FX v3.0 设计
日期2026-10-31。按用户七项需求持续实现与真实交付，保留原生Dock与不可变快照。
1. FX默认关闭，旧配置升级也先关闭；光影、后处理及景深由用户开始才参与合成。
2. 数值滑条和输入，0.01步长；不使用独立悬停窗口/透明层，排序为离散整数。
3. 多选/双击导入、拖动/上下重排、斜二测关系图；保留UUID、关键帧及绑定。
4. 相机及各层独立轨道、秒刻度、播放头、可拖关键帧、删除/记录/播放。选对象→0秒记起点→移动播放头→调整位置记终点→播放。统一时间域，预览不破坏基础位姿。
5. 灯光启用控制照明，可见性独立控制画面光球/面光标记，锚定使用动画求值后位姿与缩放。
6. Shoost仅参考视觉，独立实现Alpha内侧轮廓带、宽度/柔和度/方向，取代硬白线。
7. OBS33官方加载变更核对，32旧布局与33新布局避免重复；控制面板卸载，34未发布仅谈结构适配。
约束32层/4灯/每轨256关键帧，C++/Qt6/UTF8，复用GPU资源，渲染不等UI。V1/V2包不改；日志截图放work/v3。
