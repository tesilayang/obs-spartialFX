# OBS Spatial FX 3.2

Windows x64 / OBS 32+ 原生 Qt6 Dock 空间图层插件。v3.2 重制“镜头与动画”页面：对象/参数时间轴、独立关键帧、缓动/贝塞尔编辑、图层复位确认，以及 OBS 已有音频素材的节拍预打点。2026-11-01修订保留3.2.0版本号，可覆盖当前3.2；本次验证见 docs/v3.2/PATCH_2026-11-01.md，原始交付验证保留在 VALIDATION.md。

## 安装与升级

1. 关闭所有 OBS，双击 OBS_Spatial_FX_V3.2_Setup.exe。可覆盖升级当前 v3.2，沿用同一卸载条目；配置与个人预设保留。
2. 常规版正常启动 OBS；便携版使用安装器创建的“OBS Spatial FX - Portable”开始菜单快捷方式。
3. OBS → 停靠窗口 → OBS Spatial FX。插件在 OBS 内部运行，无外部常驻程序。
4. 卸载入口：控制面板 → 程序和功能 → OBS Spatial FX。卸载前在插件还原原始图层，避免舞台源缺失。

系统载荷只写入 C:/ProgramData/obs-studio/plugins/obs-spatial-fx，不写 OBS 的 Program Files 目录，不分发 Qt/OBS DLL。OBS 正在运行时安装/卸载会拒绝执行，静默退出码10。

OBS32 使用 bin/64bit，OBS33 使用插件目录内同名 DLL + data 新布局。便携启动器按版本设置进程级 OBS_PLUGINS_PATH，不永久修改系统环境。未来未发布的 OBS 版本不视为已测试兼容。

## 四步做动画

1. 在“空间图层”导入场景已有素材；窗口捕捉可以关联，捕捉尚未就绪时等待有效画面。
2. 打开“镜头与动画”，单击时间轴对象或下拉框选中摄像机/某个图层。展开左侧三角可选择具体参数。
3. 在0秒调整数值，点该行◇或顶部◆记录；到2秒先记录再改值。自动打帧◆+默认关闭，开启后改参数会直接在当前时间打帧；关闭时已有动画需先手工记录。
4. 播放、暂停，观察运动。时间轴菱形可以多选、拖动、复制、粘贴和删除。选择具体参数后在“关键帧 / 曲线”输入秒数、数值、缓动或拖动贝塞尔手柄。

摄像机控制视角；图层有独立位置/旋转/缩放/透明度；全画面合成独立缩放最终输出和透明度。XYZ 两页同步，滑条绝对映射−2000～2000、步长0.01，更大坐标手工输入±100000。旋转XYZ滑条为−360°～360°。缩放单位是倍率，透明度0～1。

默认时间窗为6秒，只影响显示。Ctrl+滚轮缩放、中键拖动或按钮平移、普通滚轮上下滚动轨道。播放终点只取最长保留关键帧；已删除旧播放范围和schema1～3整组动画迁移支持。当前v3.2的schema4参数轨保留，实际容量受机器内存和编辑成本限制。

“编辑基础布局”修改静态基础值，播放不会覆盖它。“复位当前图层”和“复位所有图层”均需确认，取消不改工程，确认后可撤销；锁定图层保留。对象绑定、素材顺序与光影开关保留。

## 音频节拍预打点

下方“额外功能 · 节拍”选择 OBS 已有含音频来源。可读取的本地文件后台离线分析，不重启、不定位原素材；显示能量波形、实际拍点、BPM与置信度。支持手填/点按/BPM倍频校正。

“关键帧最小拍长比例”以拍长为基准：1/4、1/2、1、2、4拍或自定义，另可限制最小秒数、源范围和偏移。先预览候选点，再确认写入当前选中参数。采样已有曲线，不凭空创造运动；保护同时间已有帧，整批可取消和撤销。最多100万候选点/单批，离线音频分析上限6小时。

没有本地文件的来源可显式采集15秒已播放PCM分析，不预测未来节拍。“联动所选媒体预览”默认关闭；开启会改变原素材播放位置，目前只支持100%速度的本地 OBS 媒体源。不同格式、网络流、真实音乐的限制见 docs/audio-v32.md 和验证记录。

## 空间、灯光与 FX

导入图层后原 OBS 项隐藏，由舞台合成；移除并还原可恢复。列表可拖动管理排序，空间前后仍按深度；结构示意图可点选图层。受光/投影/阴影/轮廓光、精确图层锚定与现有预设保留。

“开始光影处理”新舞台默认关闭；关闭时保留原颜色，不参与光照/后期/景深，几何动画继续有效。v3.1 已保存的 FX 开关保持原设置。图层进阶参数说明见 docs/v3.1/PARAMETERS.md。焦平面与景深强度移至 FX 页。

简化2.5D并非真实三维法线材质。最多32层、4灯；捕获表面最长边2048，阴影图512×512。长时间直播、其他显卡及未来版本的支持以真实验证记录为准。
