# OBS Spatial FX

**在 OBS 内制作图层空间、镜头动画、灯光和画面特效。**

OBS Spatial FX 是一个使用 C++ 和 Qt6 开发的 Windows x64 OBS 插件。它以原生 Dock 面板嵌入 OBS，直接管理当前场景已有的素材，不需要另开一个合成程序。

把背景、人物和前景分成独立图层，设置深度，再移动摄像机，就能制作具有远近视差的 2.5D 直播舞台。还可以给每个图层设置关键帧、绑定灯光、叠加 FX，并将配置保存到 OBS。

> 当前发布版本：**v3.6.3**。包含卡片式运动预设、程序装饰、时间轴补充、工程打包，以及最新灯光、阴影、辉光和星芒修复。

## 可以做什么

| 能力 | 实际用途 |
|---|---|
| OBS 原生 Dock | 停靠在 OBS 主窗口，也可浮动；切换场景和舞台后编辑对应工程 |
| 素材导入与多实例 | 从当前 OBS 场景选择已有素材；同一素材可多次导入，各实例独立运动和使用 FX |
| 2.5D 空间图层 | 调整 XYZ 位置、旋转、缩放、透明度、空间深度和同深度叠放顺序 |
| 摄像机与运镜 | 自由移动、推近拉远、旋转、视野角、看向目标和围绕目标移动 |
| 对象与参数时间轴 | 摄像机、每个图层和全画面合成都有独立参数轨；记录、移动、删除、复制和粘贴关键帧 |
| 曲线与节奏 | 线性、缓入、缓出、保持、贝塞尔等插值；按已有音频分析 BPM 和候选拍点 |
| 舞台灯光 | 点光源、简化面光源、颜色、衰减、柔化阴影、轮廓光和指定受光层 |
| 灯光跟随 | 按独立图层实例绑定，跟随其动画后的空间位置、旋转和缩放 |
| 分层 FX | 每个已导入实例独立选择效果；13 个大组、95 个子功能，按需启用 |
| 卡片式预设 | 8 种风格，18 种运动、22 种露出遮罩、21 种程序装饰；随机组合或详细手选 |
| 应用与补充 | 候选先预览；可放到指定时间，或在原时间轴末尾下一帧继续追加，支持运动撤销 |
| 工程管理 | 工程 JSON 按原场景名称恢复；完整 ZIP 携带本地素材副本，支持文件夹或 ZIP 解压后新建场景 |
| 安装与卸载 | x64 安装器、覆盖升级、便携版启动支持，以及 Windows 控制面板卸载 |

### 镜头与动画

导入、空间属性和动画在同一页面完成。直接在 0 秒设置初始布局，再在其他时间记录变化；不需要去额外的空间图层页重复导入。

- 单击时间轴对象或参数行选择编辑目标；拖动图层名称调整管理顺序。
- 位置滑条映射 −2000～2000，精度 0.01；更大坐标可在数值框输入。旋转滑条为 −360°～360°。
- 默认时间视窗为 6 秒；缩放和平移只改变显示范围。播放终点由最晚保留的关键帧决定。
- 手工记录与自动关键帧分开控制；支持上一帧/下一帧定位、关键帧位置锁、对象锁、撤销和重做。
- 复位图层和移除对象均有确认；移除最后一个实例后恢复对应原 OBS 素材的可见状态。
- 图层关系预览帮助理解前后位置；它是结构示意，OBS 预览才是最终画面。

### 灯光

最多管理 4 个舞台灯光。可选择点光或简化面光，调整位置、颜色、强度、范围、尺寸、衰减、阴影和轮廓光。光源可绑定到指定图层实例，并可选择受光层。

光照基于二维素材平面与 Alpha 轮廓近似计算，不具有真实三维模型的完整法线和体积。透明人物轮廓、前景遮挡和分层布景通常更适合这类空间效果。

### FX 特效目录

FX 页初始没有素材卡片。点击“＋”选取时间轴中已导入的实例，再开启大组图标和需要的子功能。新功能默认关闭，未激活的效果不执行对应处理。

| 大组 | 包含内容举例 |
|---|---|
| 画面模糊 | 高斯/方框、磨砂玻璃、径向、方向拖线、光圈散景、移轴、已知运动模糊、残影、像素化 |
| 画质修正 | 锐化、保边/中值降噪、SMAA、FXAA、RCAS 清晰化 |
| 颜色与调色 | 基础颜色、分色、白平衡、曲线与 LUT 等 |
| 光晕与镜头光效 | 辉光、星芒、色散、暗角、光束和镜头反光等 |
| 受光与阴影 | 环境受光、背后柔光、烛光、聚光灯、材质高光及投影 |
| 轮廓描边 | 内外描边、内发光、线稿和轮廓处理 |
| 天气设置 | 雨、水、云、热浪、火焰、余烬与烟花 |
| 故障与复古屏幕 | 数字故障、磁带、CRT、扫描、颗粒和科幻屏幕 |
| 绘画与像素风格 | 漫画、卡通、素描、油画、掌机和字符风格 |
| 形变与纹理 | 弯曲、鱼眼、折射、置换、重复和透视等 |
| 立体与自动运动 | 平面厚度、抖动、呼吸、闪烁等 |
| 裁切、遮罩与合成 | 形状/素材遮罩、透明处理、渐变叠加、纹理覆盖和混合模式 |
| 舞台与风格预设 | LED 屏幕、21:9 黑边/透明裁切、氛围柔光和醉酒眩晕 |

SMAA 与 FXAA 二选一，RCAS 可以叠加。RCAS 是单遍五点采样的自适应清晰化，不会放大分辨率或重建缺失细节。AMD Native AA 尚未实现，本版不显示。

“受光与阴影”组可使用独立局部附加光源，无需为了该组单独打开灯光页主灯。外部图片、遮罩、混合来源和 LUT 需要用户选择有效素材。

### 音频节拍预打点

可选择 OBS 已有含音频的媒体，后台分析可读取的本地文件，或显式采集一段正在输出的音频。候选间隔按拍长比例设置，也可增加最小秒数限制。

节拍功能先预览再写入，写入时采样已有参数曲线；**它不会自动替你设计镜头运动**。BPM 结果需要结合音乐检查，必要时手工修正。

### 工程管理（v3.5）

“工程管理”页提供四个入口：导出工程 JSON、导出完整工程包 ZIP、导入工程 JSON、导入完整工程包。

- JSON 保存场景、来源、空间布局、动画、灯光、FX、滤镜和原素材路径，不复制素材。导入时按存档内的场景名称匹配：同名则确认并生成恢复 JSON 后覆盖，无同名则新建。缺失素材会列出并允许手动重新链接。
- 完整包复制本地素材并记录 SHA256。导入始终新建场景，可选择含 `project.json` 的已解压文件夹，或选择 ZIP 和解压目标目录。插件在目标目录内创建新的持久素材文件夹，校验后重新链接来源；导入后需要保留该文件夹。
- 隐藏项、嵌套场景、分组、多舞台和独立实例一并保存。导入会复制依赖来源并更新引用，保护其他场景共享的原来源。
- 捕捉设备、联网服务、字体及第三方来源/滤镜需要目标电脑具备对应环境。插件会显示环境要求，缺少来源或滤镜实现时停止导入。动态脚本加载的额外素材可在打包核对窗口补充。
- 同名目标使用自定义尺寸而存档要求普通画布尺寸时，OBS 当前公共接口无法清除旧尺寸；插件会停止覆盖，需先重命名目标场景再导入。

### 风格预设与程序装饰

先勾选要运动的图层，再点击温柔舒缓、简洁几何、活泼波普、纸片拼贴、科技界面、节奏快剪、朦胧梦幻或故障实验卡片。调整动感、装饰数量与时长，生成候选，在 OBS 直接预览；满意后应用或补充至时间轴。

“详细控制”可手选运动、露出遮罩和装饰，固定满意的运动、装饰或配色，再只换其余部分。程序图形支持实心色面、厚圆环、宽色带、网点、纸条、星形、色团等，可以放在图层前方、两层之间、绑定图层或固定屏幕位置。无需提前制作透明视频。

有限周期块支持循环与节拍时长，可将指定区间转换成关键帧继续细修。露出遮罩裁切当前来源的可见区域，不等于两段独立视频的 A/B 转场。

### 当前光影行为

舞台灯光的阴影使用柔化 Alpha 缓存；局部 FX 内外阴影拥有独立角度、距离、模糊、扩散、阴影色与强度，不参与全局投影，也不使用已移除的辅助高光参数。舞台轮廓光仅识别原素材经裁切/遮罩后的轮廓，排除 FX 新增阴影或发光边缘。

辉光与星芒支持独立光效颜色和按需透明边界扩展。星芒可按目标颜色与容差选像素，射线数为 2、4、5、6。调色曲线使用输入黑、输入白、输出黑、输出白和 Gamma 五项；曝光与 Gamma 保留标准公式。

## 安装与开始使用

1. 从 [Release](https://github.com/tesilayang/obs-spartialFX/releases) 下载 `OBS_Spatial_FX_V3.6.3_Setup.exe`。
2. 关闭所有 OBS，双击安装。支持覆盖升级，场景和个人预设保留。
3. 常规版正常启动 OBS；便携版使用安装器创建的便携启动入口。
4. 在 OBS 的“停靠窗口”中打开 **OBS Spatial FX**，选择/新建舞台。
5. 在“镜头与动画”导入已有 OBS 素材，先调整 0 秒布局，再添加关键帧。
6. 按需打开舞台灯光或到 FX 页为图层添加特效；先启用少量效果观察实际渲染负担。

系统插件安装到 `C:\ProgramData\obs-studio\plugins\obs-spatial-fx`，不覆盖 OBS 安装目录，不附带 OBS/Qt DLL。OBS 运行时安装器拒绝替换文件。卸载入口为 Windows“程序和功能”中的 **OBS Spatial FX**。

如准备卸载，先在插件中移除并还原导入图层，保存 OBS 场景，避免场景仍依赖即将卸载的舞台来源。卸载前也建议备份自己的 OBS 场景集合和预设。

### 性能数据怎么理解

- v3.6.3 对预设、舞台软阴影、局部阴影、辉光、星芒和轮廓隔离分别完成对应专项；测试范围随具体修改确定。
- 最新两组 1080p60、各约 30 秒采样中，轮廓光平均渲染耗时约 0.286 ms，叠加外阴影约 0.362 ms，无新增渲染丢帧，缓存分配保持稳定。这些结果只对应测试场景。
- **没有测量整机电功耗，不能把帧耗时当作瓦数或能耗。** 不承诺其他 CPU、集显、显卡、驱动、分辨率、编码器或 OBS 版本具有与开发机完全相同的资源占用、帧率和能耗表现。
- 集显/无独显设备、NVIDIA 实机、互联网实际推流、数小时持续运行均为 **NOT RUN**。未来 OBS 版本也需单独回归。
- 每个活动 SMAA 图层在 1080p 约增加 19.8 MiB 专用图像空间，FXAA 与 RCAS 使用现有中间目标。资源紧张时先尝试 FXAA 和低强度 RCAS，再在自己的直播配置中观察 OBS 渲染丢帧。

详细命令、画面与未执行范围见 [v3.6 开发报告](docs/v3.6/)，最终阴影修复见 [轮廓隔离报告](docs/v3.6/V363_SHADOW_ISOLATION_REPORT.md)。

## 当前能力边界

- 2.5D 平面合成，不是完整三维建模、真实光线追踪或影片级离线渲染器。
- 最多 32 个导入图层、4 个舞台灯光；素材捕获表面最长边限制为 2048，简化阴影图为 512×512。
- 素材必须先能在 OBS 中正常输出。窗口捕捉的权限、目标窗口、最小化行为和捕捉方式仍受 OBS 与系统限制。
- 原 OBS 素材设置由同源实例共享，插件中的运动和 FX 则按导入实例独立保存。
- 当前层 FX 在最终舞台投影前处理，抗锯齿无法修复之后透视采样新产生的锯齿。
- 当前局部外阴影、辉光和星芒按需扩展透明处理边界；几何遮罩、裁切和画布边界仍限制最终可见区域。
- 预设中的外部文件路径不会自动把媒体文件打包给他人；素材授权和文件分发由使用者负责。

## 开发与贡献

```text
src/          插件、Dock、空间求值、动画、音频分析与 FX
src/third_party/  带授权声明的 SMAA 查找表
data/        OBS effect 着色器和插件资源
installer/    原生 Windows 安装与卸载源码
tests/       C++ 单元测试及隔离 OBS 集成测试
tools/       依赖准备、编译、测试和打包脚本
docs/        坐标约定、版本记录与使用说明
```

在 VS2022 x64 构建环境下，准备 OBS/Qt 依赖后执行：

```powershell
python tools/bootstrap.py
python tools/prepare_sdk.py "你的 OBS 安装目录"
& tools/build.cmd 4
& tools/test.cmd
```

具体依赖与实际构建路径见 [BUILDING.md](BUILDING.md)。测试桥接只用于独立 OBS 测试环境，不应部署到日常直播 OBS。`build/`、`dist/`、`work/`、`runtime/` 和 SDK 缓存不纳入 Git 历史；安装包与原始源码快照通过 Release 下载。
